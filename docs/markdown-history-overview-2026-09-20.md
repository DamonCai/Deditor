# Markdown 历史版本全览与差异导航（2026-09-20）

## 实施范围

- “历史版本与草稿”新增全览/退出全览，占满整个应用窗口并保留版本列表、内容/差异切换及恢复操作。全览中 Esc 或点击关闭仅返回普通历史窗口，保留版本、折叠与当前差异；普通窗口中再关闭才退出历史。
- 历史对比默认折叠未变更内容，差异两侧各保留一行上下文（首版为手动折叠、三行上下文，已由后续调整替代）；每段折叠可独立展开，展开远处上下文时不会跳回之前的差异；取消折叠恢复所有行，原文和行号不变。
- 上一处/下一处差异、当前差异计数和高亮；右侧按全文行位置显示差异分布，点击可定位。相邻的新增、删除、修改行算作一处差异。
- 切换版本/草稿重置定位；无差异时显示提示并禁用导航。放大和缩放窗口后重新定位当前差异，滚动仅作用于差异内容区域。
- 中英文同步，复用 Button。长读取错误内部滚动；较低的窄窗口缩短版本列表，保留差异阅读空间；暗色滚动条跟随主题。
- 仅历史对比启用新导航，普通文件对比保持原有控件。未修改历史保存格式、保留数量、恢复权限或原文。

## 后续交互调整：铺满窗口并返回历史窗口

按用户反馈，全览取消四周 12px 留白及圆角，宽高均为应用视口的 100%。Esc 和右上角“关闭”共用分层退出逻辑：全览时只退出全览，回到普通“历史版本与草稿”窗口；普通窗口时关闭整个历史弹窗。恢复/作为新文档打开仍执行其原有操作。

三轮不同维度复核：

1. 正向：1280×800 中文亮色全览实测边界为 `(0, 0, 1280, 800)`；Esc 返回 960×700 历史弹窗。
2. 边界：720×800 英文暗色实测边界为 `(0, 0, 720, 800)`，无横向溢出；普通窗口 Esc 仍可关闭。
3. 连续操作：选第一版 → 对比 → 折叠 → 第 2 / 3 处 → 全览 → Esc，保留所选版本、四处折叠及第 2 / 3 处；再次全览 → 点击关闭 → 选择第二版，对比更新为第 0 / 0 处。组件测试确认 DiffView 未卸载，返回行为不触发外层关闭。

9 历史差异组、145 通用回归与 8 分隔线组、生产构建通过。浏览器页面及服务已关闭。本次后续调整未重新构建或验收 macOS/Windows 原生包；上节 macOS 结果仅对应首版。未提交推送。


## 后续调整：默认尽量折叠相同内容

历史版本/草稿对比打开时默认折叠，差异两侧的上下文从各三行缩到各一行。文首、文尾与差异之间多余的相同行均收起，三行相同内容夹在两处差异之间时也折叠中间一行。完全相同的版本显示“内容完全相同”及一条整段展开入口。展开/收起总开关依据是否有相同内容启用，纯新增/删除且没有相同行时禁用。切换版本恢复默认折叠；全览往返保留用户当前展开、折叠与导航状态；普通文件比较不启用此默认行为。

三轮不同用例验证：

1. 正向：120 行自建文档包含三处修改，打开对比直接显示 9 行（3 行修改 + 6 行上下文），其余 111 行分四段折叠；展开全部恢复 120 行。
2. 边界：完全相同的 100 行文档默认显示 0 行原文及一条折叠入口，可展开全文再收起；三行相同内容的短间隔、空版本、纯新增/删除、Unicode 和万行文档均通过。
3. 连续操作：下一处差异 → 全览 → Esc/关闭返回历史 → 切版本，以及展开/收起后继续导航，均保留或按版本正确重置状态。1280 中文亮色与 720 英文暗色真实浏览器验证通过，窄窗无横向溢出。

最终 11 历史差异组、7 会话组、145 通用回归、8 分隔线及生产构建通过。未重打原生包，未新增 macOS/Windows 验收结论；未提交推送。浏览器测试页与临时服务已关闭。

## 2026-09-20 独立对比全览与工作区搜索定位
