# Markdown 工具栏与文件夹间距验证

## 最新调整：下拉色板（替代独立色块控件）

参考 [Microsoft Word 字体颜色说明](https://support.microsoft.com/en-us/office/change-the-font-color-in-a-word-document-37484b84-1605-48fc-8771-366913e5700c)，文字颜色与高亮均改为一个带下拉箭头的字母按钮。点击展开 50 个主题色、10 个标准色；点击色块立即应用并收起。下方自定义区域提供取色器、同步 HEX 输入框和应用按钮，支持三位/六位色号，非法输入禁用提交。选同色不会取消样式，改色替换当前选区原有同类颜色 span。弹层通过 portal 展示，避免被两行工具栏裁切。

轮 1 — 用例：点击色块与自定义色号。
  期望：色块一步应用，自定义颜色只在确认后写入，色号与取色同步。
  实测：浏览器选择 #4472C4 直接写入选区并收起；自定义 #008080 替换原色；取色器设为 #123456 时 HEX 同步显示。
  结果：通过。

轮 2 — 用例：非法 HEX、简写 HEX、同色重复与完整 span 选区。
  期望：非法输入不可提交，简写正规化，重复选择不移除颜色或叠加同类 span。
  实测：非法值禁用应用并显示提示；abc 转换为 #AABBCC；重复选择 #C00000 和选中整个 span 再选同色均保持单层样式。
  结果：通过。

轮 3 — 用例：键盘、取消、文档切换及文字色/高亮组合。
  期望：Esc 关闭并恢复按钮焦点，方向键可选色，文档切换不误写入。
  实测：Esc 恢复高亮按钮焦点；ArrowRight 从 #FFFFFF 移动到 #222222，Enter 应用；切换文档后色板关闭、目标文档未变；文字色与高亮组合测试通过。
  结果：通过。

轮 4 — 用例：亮暗主题、窄窗口与完整回归构建。
  期望：色板不被裁切，平铺工具栏保持可用，原功能无回归。
  实测：亮/暗主题截图检查通过；720px 窗口下工具栏 65px 高、无横向溢出，色板 272px 宽且完整位于视窗内。回归 55 项通过，生产构建通过（保留既有大 chunk 提示）。
  结果：通过。

验证使用真实 React / CodeMirror 组件及浏览器；取色器数值同步已验证，未验证 macOS/Windows 安装包的系统取色面板。

## 改动与功能逐项核对

左侧工作区组之间的 margin 从 12px 调为 5px，上内边距从 10px 调为 5px，保留分隔线。工具栏保持 36px 高度，常用操作直接展示，其余收进“格式 / 插入 / 更多”。窄窗口中的隐藏操作仍可在菜单内使用。

| 功能 | 调整与检查结果 |
| --- | --- |
| 加粗 / 斜体 / 删除线 | 支持再次点击取消，保留文字选区，显示激活状态；修复斜体误拆加粗标记 |
| 行内代码 | 自动选择足够长的反引号，兼容文字内部及首尾的反引号；支持取消 |
| 标题 | 原 H1–H3 扩展为正文、H1–H6，切换级别替换已有标记 |
| 无序 / 有序 / 任务列表 | 切换列表类型不叠加前缀；有序列表逐行编号；选区恰好结束于下一行开头时不修改下一行 |
| 引用 | 再次点击取消，保留缩进 |
| 文字颜色 / 背景高亮 | 在格式菜单选色，点击“应用”才写入；拖动调色板不会连续插入标签 |
| 分割线 | 自动补齐必要空行，避免在段落中插入后变成标题语法 |
| 代码块 | 单个表单指定语言，保留选中文字；内部含反引号时增加外层围栏长度 |
| 表格 | 表单指定 1–20 列、1–50 数据行，插入后选中首个表头；无效数量不能提交 |
| 链接 | 同一表单填写显示文字与地址；无选区有默认文字，支持带空格、括号的地址和标签转义 |
| 图片 | 同一表单填写描述与 URL / 本地路径；可取消，不改动正文 |
| 字号 | 在更多菜单明确标为“编辑器字号”，显示数值；10 / 28 边界禁用相应按钮 |
| 编辑 / 实时预览 / 阅读 | 保留共用分段控件；阅读时禁用写入操作，切回编辑立即恢复 |
| 撤销 / 重做（新增） | 根据历史记录启用，工具栏动作独立成一次撤销；窄窗口可在更多菜单访问 |
| 行内 / 块级公式（新增） | 复用已有公式渲染，包裹选区或插入块级公式模板 |
| Mermaid 流程图（新增） | 插入可预览的流程图模板，选中 Start 便于修改 |

插入表单捕获原文档与选区；文档在提交前发生变化时拒绝写入并提示，切换标签或阅读模式关闭表单。新增文案均补齐中文、英文。
