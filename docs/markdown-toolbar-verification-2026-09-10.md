# Markdown 工具栏与文件夹间距验证

## 改动与功能逐项核对

左侧工作区组之间的 margin 从 12px 调为 5px，上内边距从 10px 调为 5px，保留分隔线。工具栏保持 36px 高度，常用操作直接展示，其余收进“格式 / 插入 / 更多”。窄窗口中的隐藏操作仍可在菜单内使用。

| 功能 | 调整与检查结果 |
| --- | --- |
| 加粗 / 斜体 / 删除线 | 支持再次点击取消，保留文字选区，显示激活状态；修复斜体误拆加粗标记 |
| 行内代码 | 自动选择足够长的反引号，兼容文字内部及首尾的反引号；支持取消 |
| 标题 | 原 H1–H3 扩展为正文、H1–H6，切换级别替换已有标记 |
| 无序 / 有序 / 任务列表 | 切换列表类型不叠加前缀；有序列表逐行编号；选区恰好结束于下一行开头时不修改下一行 |
| 引用 | 再次点击取消，保留缩进 |
| 文字颜色 / 背景高亮 | 在格式菜单选色，点击“应用”才写入；拖动调色板不会连续插入标签 |
| 分割线 | 自动补齐必要空行，避免在段落中插入后变成标题语法 |
| 代码块 | 单个表单指定语言，保留选中文字；内部含反引号时增加外层围栏长度 |
| 表格 | 表单指定 1–20 列、1–50 数据行，插入后选中首个表头；无效数量不能提交 |
| 链接 | 同一表单填写显示文字与地址；无选区有默认文字，支持带空格、括号的地址和标签转义 |
| 图片 | 同一表单填写描述与 URL / 本地路径；可取消，不改动正文 |
| 字号 | 在更多菜单明确标为“编辑器字号”，显示数值；10 / 28 边界禁用相应按钮 |
| 编辑 / 实时预览 / 阅读 | 保留共用分段控件；阅读时禁用写入操作，切回编辑立即恢复 |
| 撤销 / 重做（新增） | 根据历史记录启用，工具栏动作独立成一次撤销；窄窗口可在更多菜单访问 |
| 行内 / 块级公式（新增） | 复用已有公式渲染，包裹选区或插入块级公式模板 |
| Mermaid 流程图（新增） | 插入可预览的流程图模板，选中 Start 便于修改 |

插入表单捕获原文档与选区；文档在提交前发生变化时拒绝写入并提示，切换标签或阅读模式关闭表单。新增文案均补齐中文、英文。

## 不同用例验证

轮 1 — 用例：常用文字格式、标题与列表操作。
  期望：格式可添加/取消，每次操作可撤销，标题和列表不堆叠标记。
  实测：CodeMirror 实例测试覆盖五类包裹标记、撤销、H6/正文和列表转换；浏览器中加粗激活状态与再次取消正常。
  结果：通过。

轮 2 — 用例：反引号、空链接、特殊 URL、行边界与表格数量边界。
  期望：语法可正确解析，不误改相邻行，无效表格不能提交。
  实测：反引号首尾和内部组合通过 Markdown 解析断言；浏览器链接地址中的空格、括号正确保留；3 列、2 数据行生成 3 个 th / 6 个 td；0 列在浏览器被拦截，正文未变。
  结果：通过。

轮 3 — 用例：调色、字号、插入后继续编辑与阅读/文档切换。
  期望：调色仅在应用时写入，字号边界受控，阅读不误写入，跨文档不误插入。
  实测：浏览器及回归测试确认 #008080 仅应用一次；14→15→14 正常，10/28 边界禁用；阅读按钮可切换、编辑菜单禁用；切换后另一文档内容保持原样；捕获目标在原文档变更后拒绝提交。
  结果：通过。

轮 4 — 用例：实际浏览器布局、主题、键盘和新增预览。
  期望：桌面及 720px 窄窗口无工具栏溢出，菜单/表单可键盘退出，公式及图表可见。
  实测：720px 窗口工具栏宽 496px，scrollWidth 同为 496px，高 35px（外壳含边框 36px）；工作区组间间隔 5px。亮/暗主题菜单及表单视觉检查通过；Esc 关闭菜单并恢复触发按钮焦点，表单 Shift+Tab 循环到插入按钮，Esc 取消。块级公式生成 1 个 KaTeX 元素、无 katex-error；Mermaid 显示 Start→End 流程图。
  结果：通过。

轮 5 — 用例：完整相邻回归与生产构建。
  期望：其他编辑、预览、目录、文件树及 XMind 相邻用例保持通过，TypeScript 和构建无错误。
  实测：`npm run test:regression`：53 passed, 0 failed；`npm run build`：通过，保留原有大 chunk 警告；`git diff --check`：通过。
  结果：通过。
