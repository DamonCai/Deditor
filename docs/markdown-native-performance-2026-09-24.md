# Markdown 阅读编辑：Rust 恢复增量化与视图复用

本轮按“保持现有功能交互，以性能为优先”的要求实施。承接同日[连续编辑优化](markdown-reading-performance-2026-09-24.md)，进一步处理恢复快照、正文目录和主题切换。没有改变文件格式、保存触发时机、撤销组数，也没有增加文档大小或内容限制。

## 实现与取舍

### Rust 承接恢复快照重建和写盘

原先恢复保存会在 WebView 中序列化所有标签的正文和已保存正文，再通过 IPC 发送完整 JSON。现在前端只发送变更文本及少量元数据；Rust 按窗口维护最后成功写入的文本，使用共享分块重建快照，在 `spawn_blocking` 中执行原有原子写盘及草稿历史流程。磁盘仍为原来的 v3 JSON，原有读取和迁移逻辑不变。

增量基于成功确认的版本，失败不推进基线；后端状态丢失或确认丢失时全量重同步。队列仍串行，关闭/退出仍等待最后快照。元数据在原保存边界冻结，避免慢写盘时被后续设置变化修改。UTF-16 坐标及 JSON 编码保留中文、emoji、转义和孤立代理项。

代价是 Rust 保留一份当前可恢复文本的 JSON 编码缓存，首次发送仍为全量；磁盘继续写完整快照，保留既有恢复语义。未更改普通文件保存/读取命令的并发顺序，也未把编辑器的交互事务移出 WebView。

### 正文目录按行复用

沿用原 markdown-it 解析器及标题 ID，返回结构化目录；安全文本节点更新仅变化的行，跳过千行目录的 HTML 生成、清洗和整批 DOM 替换。作者 HTML 仍走原显示清理流程。跨段引用、重复标题、嵌套标题和 CRLF 的目录输出与原渲染逐项一致。

### 主题原位更新

主题切换保留 ProseMirror、表格和内嵌编辑器，只刷新与主题有关的代码着色、图表及保留块。CodeMirror 使用 compartment 切换，旧异步结果按版本取消；新插入块读取当前主题。首轮千节浏览器页面在旧主题重建路径发生崩溃，本轮修复后同规模明暗往返、输入和撤销通过；不把首次失败算作通过。

## 性能对照

基线为本轮开始时冻结的相关源码，包含上一轮 AST/标题装饰优化。组件使用同一 JSDOM + 真实阅读组件脚本，1000 节、1001 表格、约 742KB；恢复链路使用实际前端编码器和实际 Rust 产品模块，release 编译并写自建临时文件。测量不代表原生按键到屏幕绘制延迟。

入口 chunk：2049.38→2051.41kB（+2.03kB，+0.10%），gzip 656.12→656.88kB（+0.76kB）。这是两次整合工作区构建的变化，期间含并行剪贴板改动，不能把全部体积增量归给本优化。未新增运行时依赖；serde_json 仅开启已有 crate 的 raw_value 特性。

React Profiler 的100次输入仍为 App 0、文件树0、状态栏100、标签栏100、EditorHost 100次，与上一轮一致；本轮收益主要在快照/目录/节点内部工作，而非隐藏必要 React 更新。

同机三轮串行、修改前后交替执行；组件每轮5次输入、3次主题更新取中位数，再取三轮中位数。恢复每轮15次编辑，分别取中位数。每个恢复标签包含912000字符正文及保存基线。

## macOS 实际验证

仅使用新 bundle ID `com.deditor.nativeperf20260924` 的隔离应用及自建 714852 字节 Markdown，未读取或改动日常应用状态和用户文档。

1. 阅读编辑中搜索定位正文后插入 ` native-check`，dirty 状态和 Rust 恢复 JSON 正文与预期逐字一致；磁盘正文尚未改变。
2. 切换暗色，单次撤销恢复干净状态，重做再次得到预期正文。
3. File → Save 后文件为 714865 字节，与预期逐字节一致，SHA-256 为 `011251155dce18f18810a9f1c622fa25276cb0ef83bf4910c1ccbcd324d33680`。
4. 菜单退出，确认进程退出；重启恢复 `large.md`、暗色、阅读模式及已保存文本。随后关闭文档回到欢迎页，退出测试实例并确认停止。

这里的重启是已保存文件恢复，不扩展为未保存草稿退出的原生验收；后者有本轮实际 Rust、关闭队列及既有原生历史证据。未新增 Windows、系统 IME 候选窗或数小时 WebView 内存结论。

## 剩余边界

仍有全量 Markdown 解析、长文首次挂载和浏览器布局成本，不能承诺任意规模或无限时长绝无卡顿。本轮没有通过更换 Markdown 解析器来改变既有语法行为。共享目录只保留当前上下文，Rust 窗口销毁/标签关闭释放对应缓存；长期原生内存仍需独立持续观察。

测试服务、浏览器页面及隔离应用已关闭；未替换日常安装应用，未提交或推送。工作区中并行剪贴板和 PlantUML 改动保留，不归为本轮性能成果。
