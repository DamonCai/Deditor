# HTML 动态渲染修复（2026-09-20）

用户提供 `gateway-traffic-flow.html`：图形、字段列表和交互全部由内联 JavaScript 创建。原 HTML 预览同时设置空 sandbox 和 `script-src 'none'`，实际浏览器复现只有标题、工具栏和空框，图形节点数为 0。

## 修改

- HTML 独立 iframe 使用 `sandbox="allow-scripts"`；不授予同源、顶层导航、弹窗或表单权限。
- CSP 允许内联、HTTP/HTTPS 和 asset 脚本，继续禁止 object、嵌套 frame、表单提交，不开放 eval；保留文件自身 CSP。
- 原有路径解析、片段链接、当前未保存内容预览及源码保持不变。没有改动 Markdown HTML 清理逻辑。
- 增加回归断言及可重复浏览器入口 `tests/html-preview-review.html`。默认只含自建样例；`?supplied` 使用被忽略的用户提供文件副本。副本通过 `.txt` 提供原文字节，避免 Vite 向 HTML 响应注入开发脚本。
