# 阅读编辑文末代码块操作修复（2026-09-12）

## 范围与复现

仅处理用户反馈的文末落点、代码整块选择删除、退出代码后继续正文，以及相关历史与保存；不扩大为所有 Markdown 操作验收。开始时工作区干净。

真实浏览器自建样例复现两条失败：

- 代码最后一行中间按 ↓，焦点仍被内嵌代码编辑器占用。旧代码要求光标精确位于最后一个字符后。
- 点击文末代码块下方空白再 Enter，实际原文在代码块**前面**插入 `<br />`，没有获得文末正文落点。

旧 Escape 已能选择节点，但缺少明显的鼠标整块选择入口，无法据此否认用户的操作困难。

## 修改

- 点击文章最后一块下方空白：普通正文定位到末尾；代码、公式、图片、表格、列表或保留块后按需创建正文段落。加载文档本身不附加空段落；右键、控件与块内编辑不触发该处理。
- 代码第一／最后一个显示行的 ↑／↓ 可离开代码；自动折行中间的显示行仍在代码内移动。Cmd/Ctrl+Enter 可直接到代码后正文；普通 Enter 仍在代码内换行。
- 代码左侧增加“选中整个代码块”按钮，中英文同步。选中后显示整块轮廓，可 Backspace/Delete 删除；Escape 的原有整块选择继续可用。整块选中后 Enter／↓ 进入后方正文，↑ 进入前方正文。
- 控件不改变代码排版尺寸；代码焦点本身仍不显示选择轮廓。按钮与原有块类型提示在左边上下错开。
