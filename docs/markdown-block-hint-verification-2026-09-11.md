# 完整 Markdown 文档的当前块提示验证

日期：2026-09-11。用户要求提示不限于 H1–H6，并使用复杂完整 Markdown 文件测试。

## 行为

页边仅显示当前块的提示：H1–H6、正文 ¶、引用 >、无序列表 -、有序列表 1.、任务 [ ]、表格 | |、代码 </>、公式 $$、图表 UML、图片 IMG、分隔线 ---，以及 HTML、YAML、保留原文 MD。嵌套结构优先显示最内层类型；引用内标题仍显示标题级别。

折叠文本光标或整块选中时显示；一段文本被选中、编辑器失焦、只读或实时预览时隐藏。代码、公式、图表和原文块内部的 CodeMirror 光标同样生效。

提示元素位于可编辑文档之外，独立占用页边空位，不覆盖列表编号、复选框或单元格，不参与原文序列化、复制或撤销。位置更新只读取块位置并移动提示，不调整滚动位置。

## 自建完整样例

样例：[markdown-complex.md](../tests/fixtures/markdown-complex.md)，273 行，11,594 字节。仅使用自建数据与图片。

包含 YAML、六级标题、中文与行内格式、转义、多层引用、引用内标题/列表、三级列表、任务嵌套、对齐表格与单元格换行、分隔线、TypeScript、嵌套围栏、行内/块级公式、Mermaid 流程图与时序图、本地图片、行内 HTML、details、引用定义、脚注保留语法，以及 18 个长文章节和文末定位段落。脚注等未支持的语法仍按原文保留，不把保真测试当作完整渲染支持。

浏览器入口：`/tests/markdown-visual-review.html?complex`；可叠加 `&dark` 或 `&parity`。不加载应用持久化状态或用户文件。
