# Markdown 原生光标与长文输入验证（2026-09-12）

本次继续处理 Typora 差距中的输入稳定性和长文交互，不增加导入导出能力，不调整字体与共享正文样式。下列结果只代表已实际覆盖的范围，真实中文候选、Windows 和长时间压力验收仍未完成。

## 修改

- 阅读编辑使用浏览器原生光标，保留上游格式边界的左右键处理、拖放光标和块间光标。原虚拟光标每次更新重启动画时读取布局，在 500 节样例上单次插件更新耗时 41.5–44.3ms。新插件仅复用按键处理，不创建虚拟光标、隐藏原生光标或安装几何测量监听。
- 关闭搜索后，输入不再重新扫描整篇文档。打开搜索时按不可变文本块缓存结果，编辑后复用未变化块。查询在原文上匹配，修复前置 `İ` 转小写扩长造成后续搜索选区偏移的问题，覆盖中文、表情和正则特殊字符。
- 可访问性属性只在值变化时写入，避免无效 DOM 属性更新触发编辑器协调；标题锚点装饰按不可变文档缓存，选区移动不重复遍历标题。
- 测试页支持 `?long&sections=500`，并增加仅用于测试的插件更新耗时记录。
