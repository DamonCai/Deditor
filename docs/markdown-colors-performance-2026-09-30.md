# Markdown 颜色功能性能回归（2026-09-30）

用户要求新增背景色后补充性能回归。产品基线为 `3e2dcb2`，颜色功能版本为 `dbb16cb`；本轮新增性能脚本及记录，不调整产品行为、历史容量或内容规模限制。

## 测量方法

同一台 macOS arm64、Node v22.16.0，依赖不变。通过 `git archive` 将基线源码放入忽略的证据目录，用现有 `perf-markdown-component-profile.mjs 1000` 的 `DEDITOR_READING_BASELINE` 加载基线。顺序为前1／后1／后2／前2／前3／后3，各自独立进程，性能任务串行执行。

自建复杂 Markdown 共 742,030 UTF-8 字节、299,244 字符，包含千节标题、引用、格式正文及 1001 张表格。每轮分别取 5 次正文、5 次标题和 3 次主题操作的中位数，再取三轮中位数；初始化取三轮中位数。真实 React／ProseMirror 组件及源码同步在 JSDOM 中运行，不包含原生布局、输入法、磁盘保存或应用启动的全部成本。

## 新增颜色专项

`npm run perf:markdown-colors` 已接入 `perf:all`，使用真实工具栏与阅读编辑组件，隔离所有文件和设置接口，只处理自建内容。覆盖：

1. 普通长文：1000 段、782,889 字节，输入与三种颜色分别计时；每次操作后单次撤销，逐字核对源码。
2. 大量底色：相同长文中 250 段带底色，共 794,639 字节，检查解析、输入及三种颜色操作。
3. 大表：51 行（含表头）×20 列，共 1020 格；部分格预置底色，检查单格输入、三种设色以及整表一次设色／一次撤销。
4. 连续编辑：各场景连续 60 次改底色，对比前后各 20 次耗时，执行 GC 后记录历史保留堆增量；60 次撤销恢复原文。

两次独立专项加完整套件内的一次，共三次执行，各轮中位数再取中位数。输入每轮 25 次舍弃前 5 次，三种颜色每轮各 15 次舍弃前 3 次；下面是组件热操作成本，不是取色器第一次打开或首次网络加载成本：

| 场景 | 输入 | 文字颜色 | 突出显示 | 背景色 | 连续底色前20次 → 后20次 | 60步历史堆增量 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 普通千段 | 3.29ms | 3.20ms | 3.33ms | 3.94ms | 3.57 → 3.30ms | 1.75MiB |
| 250段有底色 | 3.04ms | 3.22ms | 3.79ms | 3.66ms | 3.36 → 2.97ms | 0.94MiB |
| 1020格表格 | 165.29ms | 63.24ms | 64.25ms | 62.59ms | 62.60 → 63.74ms | 44.07MiB |

1020 格整表设色三次为 193.51／202.36／203.40ms，中位数 **202.36ms**；单次撤销恢复原文。单格输入仍有约 165ms 的组件开销，不称大表输入已经无延迟。普通段落与带色段落在同进程依次运行，存在热身顺序差异，不能将后者略快解释为设置底色带来性能提升。

脚本的秒级阈值用于阻止严重失速，并非流畅帧率承诺；手工前后对比仍用于判断较小的变化。历史堆增量阈值为段落 32MiB／表格 128MiB。60 步记录也不等同数小时内存泄漏验收。表格历史需要保留较多结构，内存占用单独报告，不能将它当作泄漏结论。

## 回归轮次

- 轮1（基础）：普通长文输入及三种颜色；期望颜色实际写入、单次撤销恢复，实测全部通过。
- 轮2（边界）：742KB 复杂文档、千段底色、1020 格批量操作；期望前后无明显退化、范围正确，实测三轮对照及批量源码核对通过，耗时如上。
- 轮3（组合）：连续 60 次改色、前后耗时、GC 后历史堆和完整撤销；期望无持续失速且原文可恢复，三个场景均通过。
- 轮4（横向）：完整 `npm run perf:all` 串行通过，覆盖状态、React、启动、持续操作、文档／XMind、9 项 Rust 性能测试、Markdown 预览／输入／切换／编辑／历史及实际 Rust 恢复传输。111 个前端到 Rust 的快照语义检查通过。套件中原有“before/after”表示各自历史算法对照，不能混作本次颜色版本的对比数据。
- 轮5（功能与构建）：最终颜色专项 11 组、通用回归 149 项、分隔线 12 组以及 `npm run build` 通过；`git diff --check`、新增脚本语法检查通过。保留既有 React act／KaTeX／npm 配置和大 chunk 提示。本轮仅增加性能脚本、命令和文档，未重复完整功能 `test:all`；颜色功能版本的全量通过证据见[功能记录](markdown-colors-2026-09-30.md)。
