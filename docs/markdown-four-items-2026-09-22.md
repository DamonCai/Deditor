# Markdown 四项处理与整合验证（2026-09-22）

用户要求并行处理两项待实现和两项性能工作。本次三个子 agent 分别负责配对、词典、解析及初始化优化，主任务负责真实界面矩阵、历史渲染优化、原生整合与待办清理。基线为干净提交 `0fe428d`。

严格冻结性能 A/B 三轮：1000 节初始化中位 10704→7645ms，标题编辑 1011.1→300.4ms；正文普通编辑基本不变。真实万行历史稀疏导航中位 123.9→45.5ms、密集 167→79ms，所有行仍在 DOM。5000 文件搜索五轮中位 72.785/71.364/65.087ms（区分大小写/忽略大小写/零命中），每轮扫描全部文件。

没有通过隐藏正文、限制文件大小/扩展名、减少合法图表或限制词条数量换取性能。主入口包体 2,037,323→2,049,311 字节，gzip +0.81%；新增功能使包体略增。

## 验证结果

- 完整 `npm run test:all` 退出 0，46 个直接入口、50 个嵌套脚本，日志 924 条 PASS、0 FAIL。PASS 行数不等同独立断言数。执行期间最后尾空格修复追加了受影响回归：107 阅读集成、23 输入/剪贴板、13 基础、7 导航、34 表格，合计 184 项/组；最终配对专项 13 组通过。
- 词典专项 5 组；Rust 词典 3 项通过，覆盖持久化、16 线程 revision/通知顺序及写失败字节保持/重试。新工厂 2 组、上下文 6 组通过。
- 最终完整 `npm run perf:all` 退出 0，含 Rust 性能 9/9 与新增 5000 文件重复矩阵。重基准期间没有并行构建或其他性能采样。
- 最终 `npm run build`（含类型检查）与独立 macOS debug bundle 构建通过。实际浏览器中英文、亮暗、720px 词典操作及配对原文核对；原生实际词典落盘、重启保留、文档隔离、逐键配对和菜单保存通过。

日志保存在被忽略的 `tests/artifacts/markdown-four-items-2026-09-22/`：`test-all.log`、`final-inline-regression.log`、`rust-spelling.log`、`perf-all.log`、`build-after-final.log`、`native-build-final.log`、`rust-search-matrix-summary.json`。测试入口和方法随代码提交；跨机迁移原始日志需另带该目录。

## 保留的明确边界

1. 普通原生包批量输入曾观察到额外闭合星号，原因未定。独立诊断包四次重演、99 次单字符事件及保存均正确，不能抵消首次观察；后续须抓到异常事件与源码再定因。未猜测归因工具或输入法，已在待办输入链一行明确保留。
2. 本机原生系统拼写未显示可观察红线，也未弹出系统建议菜单；词典管理、存储和 DOM 检查资格联动通过，不等于原生红线消失/恢复通过，保留在系统拼写待验收。
3. 1MB 阅读正文三位置输入中位约 234–280ms，实时预览最后输入到最终 DOM 约 366–521ms；仍存在长文成本。普通正文和 300 围栏主题切换未证明加速。千节初始化仍以秒计。测量规模完成不意味着任意文档即时响应。
4. 超过 8 标签后源码冷恢复保持内容、选区和可见光标，但估计高度使像素位置变化；不声称像素精确。未新增 Windows、真实中文候选、长期 WebView 内存或真实远程服务结论。
