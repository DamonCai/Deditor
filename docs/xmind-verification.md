# XMind 本地渲染与编辑验证

日期：2026-09-09。环境：本机 macOS Apple Silicon，React/TypeScript/Vite，浏览器实际布局检查 + jsdom 组件回归。目标是同时改善原文件外观和 XMind 风格的编辑操作。本轮未提交 Git、未发布安装包。

## 实现内容

- 将 XMind 主界面从 mind-elixir 转为本地 SVG 场景。直接读取原始 content.json：工作表、主题/节点样式、字体/颜色/形状、结构方向、左右分支数量、自定义子树、自由主题坐标、图片、备注、标签、概要、边界和联系。
- 本地打包 XMind 开源 NeverMind 字体的四个字重，补齐字体授权文件。字体和工作台按需加载，打开文件不向服务端上传内容。
- 同一画布提供阅读/编辑、平移缩放、适合窗口、大纲、主题搜索、格式面板。支持 Tab 子主题、Enter 同级主题、F2/双击改标题、Shift 多选、删除、拖拽改层级/转自由主题、复制粘贴、撤销重做、工作表切换/新增、备注/标签/样式编辑、添加概要/边界/联系/批注。
- 每次编辑只替换 ZIP 内 content.json，保留其余成员原始压缩字节和未知 JSON 字段。未改变的文档返回原始完整字节；撤销至初始状态同样返回原始字节。notes 的纯文本内容主动修改后清除旧 realHTML，避免重新打开显示过期富文本。
- 保存、另存为、关闭、失焦以及卸载前刷新标题草稿；文件标签会话缓存保留工作表、视口及 50 步撤销历史，关闭文件时释放缓存。编辑回写的 store 通知不会重新解析文档或重置画布。
- 修复实际浏览器发现的双击指针捕获问题、左侧概要与父主题重叠、多行标题在属性面板失焦后变化、Esc 被 blur 回写，以及默认字体测量与显示字重不同的问题。

## 性能 BEFORE / AFTER / DELTA

保存基准：1001 主题 + 1 MiB 附件，10 次 ZIP 序列化；预热一次，另三次取中位数。BEFORE 是原 saveSheetEdit 转换/解压/重压路径，AFTER 是已解析、已编辑的原始模型写回路径。测量不含原生磁盘 IO、首次解压、React 绘制、逐键输入或大型不可压缩附件场景。

| 指标 | BEFORE | AFTER | DELTA / 代价 |
| --- | --- | --- | --- |
| 10 次 ZIP 序列化 | 92.904 ms（94.552 / 92.602 / 92.904） | 3.998 ms（3.998 / 4.178 / 3.868） | -88.906 ms，-95.70%；保存只压缩 JSON；保留原档案与解压资源在会话内存中 |
| XMind 懒加载 JS | 114.88 kB / gzip 39.58 kB | 58.45 kB / gzip 22.03 kB | JS -56.43 kB（-49.12%），gzip -17.55 kB（-44.34%）；去掉通用引擎，增加专用模型/交互 |
| NeverMind 字体资源 | 0 | 393.344 kB | +393.344 kB；随 XMind 加载，换取更接近原软件的文字排版 |
| 全应用入口 JS | 1105.42 kB / gzip 367.04 kB | 1113.80 kB / gzip 369.01 kB | +8.38 kB（+0.76%），gzip +1.97 kB（+0.54%）；同工作区有共享 UI / HTML 等并行修改，入口总差值不能全部归因于 XMind |
| perf:react，100 次输入的订阅探针重渲次数 | App 0，TitleBar 1，StatusBar 100，TabBar 100，EditorHost 100 | 同前 | 0；该脚本是订阅行为探针，不是 XMind 大图实际帧率 |
| 新引擎 10 次 1001 节点布局 | 未采旧引擎同口径值 | 14.588 ms 中位数（22.034 / 14.214 / 14.588） | 新增基准；未作旧布局性能提升声明 |

`npm run perf:all` 的第一次运行在既有 fuzzy 50k 的一项查询采样上出现 16.53 ms，超过 16 ms 门槛，当时同时有浏览器校准活动。未修改该算法或门槛；停止浏览器/开发服务器后重新完整运行，全部通过（含 Rust IPC 8 项，0 失败）。保留首轮超限记录，不能把一次复跑通过解释为所有运行永不超限。

## 验证边界与剩余差距

- 当前已完成两条方向的本地实现与上述样例验证，但尚不能宣称任意 XMind 文件完全一致。
- 时间轴/鱼骨图为近似布局；特殊结构、手绘效果、复杂边界/概要、联系控制点、自定义贴纸/图标等未逐项复刻。联系当前可新增/展示，未提供全部控制点和样式编辑。旧 XML 文件保留只读，未实现等保真编辑。
- ZIP 未改成员（包括内置预览缩略图）保持原始字节；缩略图不会随本地编辑重新生成。
- 局部格式文本、复杂公式/附件交互、跨原生 XMind 的完整快捷键语义仍需继续补齐。没有宣称所有 XMind 功能已经实现，也未对超大图做视口节点虚拟化。
- 系统原生 XMind 已安装，但此次电脑锁屏阻止原生 UI 自动化；未获得用户代表性文件路径，因此未完成用户实际文件在原生 XMind 中的并排验收和编辑后重新打开验收。已请求解锁和样例路径。公共样例/合成样例测试不能替代这一环。
- 没有验证 Windows 安装包、macOS 打包应用的 WKWebView 字体/快捷键/原生文件对话框行为。需要在原生环境完成这部分，才能对用户提出的最终一致性标准作完整验收。
