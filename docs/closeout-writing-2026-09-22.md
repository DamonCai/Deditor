# 阅读编辑设置与连续操作收尾（2026-09-22）

## 实施范围

写作设置新增三个独立选项：括号配对、引号配对、成对符号包裹选区。旧会话默认均开启，保持原来的行为；全局“自动闭合括号与引号”仍为总开关，关闭后这三个选项禁用并说明原因。设置自动持久化，中英文同步。

相应选项同时控制输入、跳过已有闭合符和成对退格。关闭选区包裹时，输入正常替换选区；代码、组词和 Markdown 格式输入规则保持各自已有处理。本次没有新增空选区 Markdown 格式符的自动配对，不能称为 Typora 全套输入偏好等价。

系统拼写菜单的入口修复由另一 agent 负责，写作设置同步增加 Alt/Option 右键提示。具体代码和平台边界见[快捷键与拼写菜单收尾](closeout-shortcuts-2026-09-22.md)。未增加独立词典服务或读取用户词典。

| 轮次 | 期望 | 实测 | 结果 |
| --- | --- | --- | --- |
| 1：基础输入 | 括号、引号、选区各自遵守选项，未改选项继续生效 | 5 组 B05 专项通过；真实浏览器输入 ` (` 得到 ` ()`，关闭括号配对后退格只删左括号；随后输入 ` [` 只插入单字符 | 通过 |
| 2：边界与历史 | 中文、关闭单项、旧设置恢复、逐项启停不破坏保存撤销 | 23 组输入/剪贴板回归通过，新增独立开关、选区替换精确历史、默认值与关闭值恢复断言 | 通过 |
| 3：界面与键盘 | 中英、亮暗、720/1280px 可见且焦点正常 | 真实浏览器看图；Space切换、Tab到下一项、Esc返回编辑；720px英文暗色总开关关闭时三项禁用，三行复选框与标签中心差均0px | 通过 |
| 4：长文连续操作 | 多位置输入、标签/模式切换、撤销保持原文且不累积编辑器 | 自建100节、34,641字符复杂文档；第1/20/50/75/100节逐键输入后切另一标签、切回、撤销，五次原文精确相同；源码/实时预览往返各两次，保存快照精确一致；结束1个ProseMirror和1个CodeMirror | 通过 |
