# 文件对比相同行收起与展开

普通文件对比（右键“选为对比文件”入口）复用历史版本对比已有折叠能力。默认仍显示全文；工具栏“折叠未变更内容”切换收起/全文，折叠条“展开 N 行未变更内容”独立展开对应区段。差异相邻各保留一行上下文，两侧原始行号和共享滚动保持不变。展开后焦点回到可键盘访问的对比区域。切换比较内容或文件路径重置临时展开状态。

## 验证

- 轮 1 — 用例：普通文件比较的收起、局部展开、恢复全文、再次收起。
  - 期望：100 行三处差异收起后保留 9 行与 4 个折叠区段；展开开头恢复 8 行；取消折叠恢复全文。
  - 实测：9 行/4 段 → 17 行/3 段 → 100 行 → 9 行/4 段，行号保持，焦点回到对比区域。
  - 结果：通过。
- 轮 2 — 用例：空文件、完全相同、纯新增/删除、短上下文、CRLF、中文及已有万行用例。
  - 期望：无相同行时按钮禁用；差异始终显示；展开后恢复每个原始行号。
  - 实测：全部断言通过，完全相同文件可整段收起并展开；万行投影仍完整恢复。
  - 结果：通过。
- 轮 3 — 用例：多实例独立状态、中英文切换、内容相同但路径改变，以及历史比较导航/全览/异常读取。
  - 期望：一处折叠不影响另一处，路径改变重置状态，历史版本交互保持。
  - 实测：专项共 13 组通过，含新增普通文件比较 3 组与历史比较 10 组。
  - 结果：通过。
- 轮 4 — 用例：自建 120 行浏览器样例，亮色中文宽窗、暗色英文 720px 窄窗、Tab/Enter、完全相同文件。
  - 期望：差异及两侧行号对齐，无水平溢出，键盘可展开区段，完全相同可收起全部 120 行。
  - 实测：4 段/9 行；局部展开后 3 段/17 行；全文恢复 120 行；窄窗无水平溢出；Tab 焦点轮廓和 Enter 展开正常；相同文件显示“Expand 120 unchanged lines”。
  - 结果：通过。截图位于忽略目录 `tests/artifacts/file-diff-2026-09-29/collapsed.png`。
- 轮 5 — 用例：通用回归与生产构建。
  - 期望：相邻功能回归、类型检查和生产打包通过。
  - 实测：`npm run test:regression` 149 项及 12 分隔线组通过；`npm run build` 通过；`git diff --check` 通过。构建仍有分块大小与静态/动态导入提示，回归有 React 测试挂载警告，无失败。
  - 结果：通过。
