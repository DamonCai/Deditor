# 阅读编辑向下键回跳修复（2026-09-12）

## 复现与原因

用户报告从上方连续按 ↓，光标在列表中下移后突然回到前面的 ` 水电`。仅五行短样例在浏览器和 macOS 中未稳定复现；用户在独立原生测试包中补入含引用链接、HTML 键帽和两组列表的完整自建长文后，已由助手实际重现：`sdf` 后按 ↓，行内代码源码展开，光标从第 9 行回到第 7 行。

`MarkdownDocument.sourceOffset()` 在列表换行前等非文本位置使用近似换算，可能落进前一项代码的源码范围。`inlineAt()` 原来仅据这个源码范围查找片段，未验证当前文档光标是否属于片段，因而错误展开并迁移光标。核心回归修复前得到文档位置 69，却返回范围 47–50 的 ` 水电`。

## 修复范围

`src/lib/markdownVisual/document.ts` 在展开前同时验证真实文档位置必须落在片段的 `from`–`to` 内。保留原有原生方向键、行内编辑和显示样式；本修复没有改动 Markdown 原文或 XMind。

增加两份短样例：原始五行，以及含标题、已解析引用链接/HTML 键帽的最小上下文。核心用例遍历列表中的文本块位置；集成用例模拟光标到达换行前的真实 DOM 位置，验证不展开前面的代码、选区仍位于目标段落、原文不变。该用例使用独立编辑实例，避免向后续用例遗留引用定义块的异步焦点。

本次阻止错误展开，不代表所有非文本位置的状态栏行列近似映射均已改为精确值。
