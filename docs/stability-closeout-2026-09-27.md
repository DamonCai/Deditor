# 持续稳定性专项（2026-09-27）

本轮针对 SOAK-01 / SOAK-02 补真实浏览器持续运行证据。只使用自建数据、独立浏览器标签及冻结前端 bundle；没有读取用户文档、恢复状态或原生日常安装包。运行器为 `scripts/stability-browser-soak.mjs`，不加入每次提交的 `test:all`。

## 方法与范围

运行 `node scripts/stability-browser-soak.mjs --minutes=20` 后，使用 CUA 在独立后台浏览器标签打开输出的本地 URL。页面自己执行测试，不依赖浏览器远程调试、外部 CDP 控制或访问浏览器内部状态。

- Markdown：真实 `MarkdownVisualHost` / `MarkdownVisualEditor`，200 节、200 张表、115,090 字符。每轮新标签挂载，浏览器 DOM 输入经过真实 MutationObserver → 产品编辑管线，核对编辑、单次撤销和重做全文精确一致。
- XMind：真实 `XmindView`，3 张工作表，每张 1,001 节点。每轮挂载新文档，执行 12 次缩放点击、6 次工作表选择和6次滚轮平移。逐次断言缩放和平移实际改变 SVG viewport、目标工作表被选中，结束时完整 data URL 与初始 ZIP 字节一致。
- 各轮挂载时交替明暗主题，使用真实 store `closeTab` 关闭两个文档；隔离入口复制主入口对关闭 Markdown session 的释放动作，不启用真实文件 I/O、应用恢复或自动保存。
- 每5轮在文档关闭后记录浏览器 `performance.memory`、页面 DOM 节点数、存活 Blob URL 数量、编辑器/画布数量、活动视觉桥及关闭标签栈长度。堆数据遵从浏览器自然 GC，不人为强制回收。未将整个共享 Chromium 进程 RSS 归到单个文档。
- 源码一次性打包，不启用 Vite/HMR，因此并行 agent 修改不会重置长跑。测试过程中不刷新标签。复跑结束后关闭测试标签，并停止输出 URL 的本地 Node 服务。

输入是测试页合成 DOM 输入，平移是合成滚轮事件；不能称物理键盘输入、IME、实际鼠标捕获拖动验收。`performance.memory` 是 Chromium 提供的 JS 堆估计，可能受取样粒度与共享进程影响，不是 WKWebView 私有内存或系统驻留内存。关闭后的可见 DOM 清零也不等于所有脱离文档的节点都已被 GC。异常记录覆盖 window error / unhandledrejection；原生 invoke 日志为隔离替身，不将它称作完整原生日志审计。
