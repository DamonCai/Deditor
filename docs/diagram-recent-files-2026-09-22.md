# 图块排序与近期文件（2026-09-22）

用户要求两项功能：Markdown中的Mermaid/PlantUML上下拖动，以及IDEA式Command+E近期文件。图块由主agent实施，近期文件独立agent实施，另一个agent审查拖动边界。保护前次收尾未提交修改；本次不提交推送、不替换日常应用。

## 功能

- 阅读编辑中，两类图块工具栏左侧新增拖动手柄，支持落点线、边缘滚动、整体移动和单次撤销；手柄聚焦时Alt+↑/↓逐块移动。保持引用/列表容器，阻止非法落点；不在全览和只读状态中拖动。
- Command+E（Windows/Linux Ctrl+E）打开近期文件，默认选上一文件；可按文件名/路径过滤、上下键选择、Enter打开、Esc关闭。文件菜单与命令面板也有入口，遵守快捷键开关。
- 全窗口共享100条最近访问路径，去重并持久化；关闭文件后仍可重开。记录从本功能启用后的访问开始，不扫描磁盘或读取系统历史。面板与其他导航/设置互斥，缺失文件有局部反馈且可继续操作。
