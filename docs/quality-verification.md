# Bug 修复、性能与 UI 验证

日期：2026-09-09。环境：本机 macOS Apple Silicon、Node 22、Rust；基线为修改前的 0.8.1。修改未提交、未发布安装包。

## 完成的修改

- 保存按标签串行执行，保存完成只更新原标签及已写入内容；保存期间切换标签、继续输入、异步格式化不会误清新内容的未保存状态。取消另存为或写盘失败不会关闭未保存标签；关闭其他标签逐个确认。自动保存跳过外部变更冲突。
- 修复以 data URL 开头的普通文本被误当二进制保存；另存为拒绝覆盖其他已打开标签的路径。XMind 仍按二进制保存。
- 修复 Unicode 忽略大小写搜索的字节边界和编辑器 UTF-16 列号；替换部分失败时同时报告实际成功数与错误。清空查询后丢弃迟到结果，失败可重试。
- 修复未命名 Markdown 的空白预览。文本编辑器与预览文档 DOM 保留最近 8 个标签，淘汰后保留撤销、书签、折叠、选区和滚动位置；预览保留搜索及目录状态。媒体和 XMind 保持挂载以保留播放及编辑会话。
- 状态栏统计改为增量计算，删除遮挡首行的重复统计浮层；按会话实际内容预加载渲染依赖。
- Markdown 工具栏增加窄窗口“更多”菜单及固定模式切换区。对话框补齐焦点约束、关闭后焦点恢复和可访问标签；确认框排队，显示在搜索面板上方。新增文案中英文齐全。

## 变化量与代价（DELTA）

| 指标 | 变化 | 代价或解释 |
| --- | --- | --- |
| 入口 JS | +7.24 kB，+0.66%；gzip +2.98 kB，+0.82% | 新增保存保护、焦点管理和缓存逻辑 |
| 文档统计 | -1239.16 ms，-99.29% | 维护增量字段；整篇替换仍需扫描受影响全文 |
| 密集搜索 | -27.58 ms，-63.78% | 容量固定的结果堆及并发协调；保留相同扫描数、命中顺序和截断语义 |
| 稀疏搜索 | 区分大小写 +5.4 ms，+7.13%；忽略大小写 +4.1 ms，+6.05% | 基线仅一次且本机 IO 波动明显，不能认定精确回退比例；本次重点收益在密集匹配，不宣称所有搜索加速 |
| 重渲染次数 | 上述各组件变化均为 0（非零基线为 0%；App 基线 0 不计算百分比） | 本次降低每次统计开销，没有降低探针的更新次数 |

冷标签重新显示需要重建 DOM。撤销历史、预览 HTML 字符串和媒体会话仍保留，因此总内存并非固定上限。按需加载未预判到的渲染器可能在首次使用时等待加载。

## 执行命令与异常记录

```sh
npm run build
npm run test:regression
npm run perf:all
cargo test --manifest-path src-tauri/Cargo.toml regression -- --nocapture --test-threads=1
cargo test --release --manifest-path src-tauri/Cargo.toml ipc_bench::find_in_files -- --nocapture --test-threads=1
git diff HEAD --check
```

- 构建、TypeScript 检查、功能回归、完整性能套件最终均退出 0。新增 `perf:document` 已接入 `perf:all`。
- 修复了旧性能脚本中的 Diff 导出名与符号提取参数错误，避免静默跳过或测空结果。
- 一次与构建同时运行的 perf:libs 中，模糊搜索最大值 16.12 ms 超过 16 ms 门槛，完整套件因此停止。未调整门槛；独立重跑完整套件通过，该项最大值 13.96 ms。
- 完整套件中的一次忽略大小写搜索为 120.9 ms；独立三次复测为 74.7 / 71.9 / 65.7 ms，保留波动记录，不据单次结果宣称改善。
- Vite 仍提示部分 chunk 超过 500 kB；入口体积未降低。npm 的本机 `python` 配置警告仍存在，与应用代码无关。
