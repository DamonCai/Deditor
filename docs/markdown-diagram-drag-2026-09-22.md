# Markdown 图块拖动（2026-09-22）

用户要求 Mermaid、PlantUML 图块上下拖拽移动。新增工具栏左侧拖动手柄，鼠标拖动显示主题色落点线，编辑区上下边缘自动滚动；松开移动整个图块，单次撤销/重做。手柄聚焦时 Alt+↑/↓ 可逐块移动。覆盖 Mermaid、PlantUML/puml/uml 的阅读、编辑和实时预览三模式；普通代码块不增加手柄。

移动遵守同一父容器的块顺序，保留引用/列表嵌套；列表必需的首段之前不显示合法落点。只读或全览不提供拖动。Esc、失焦、指针取消/捕获丢失、组件销毁、拖出当前编辑区、拖中正文变化和窗口确认关闭均取消移动。

## 四轮验证

轮1 — Mermaid与PlantUML上下拖动、跨多个块、保存及单次撤销重做。
期望：移动完整源码，顺序正确，撤销恢复原始字节。
实测：组件测试和真实浏览器通过；亮色中文将Mermaid拖过PlantUML，暗色英文720px将PlantUML拖到前文之前，均一次撤销显示原文一致。

轮2 — 不足5px的点击、原位、编辑区外、Esc、拖中编辑。
期望：不产生意外正文修改或残留落点。
实测：对应专项全部通过。

轮3 — 三模式、四种语言标识、嵌套引用、键盘移动及只读。
期望：各图块可排序，引用不被拆出，隐藏只读手柄。
实测：对应专项全部通过；浏览器核对中英亮暗工具栏、窄窗和实际拖动。

轮4 — 列表必需首段、关闭提交、拖中只读、捕获丢失及销毁。
期望：拒绝非法结构和过期拖放，关闭后不回写。
实测：独立审查后补专项，全部通过。

命令：`DEDITOR_TEST_FILTER='drag round' npm run test:markdown-diagram-modes`（4组），原图表完整链加首3组为28组通过；最后非法目标检查只影响新增拖动，再过4组。107阅读集成、通用回归和生产构建通过。PlantUML浏览器使用明确标记的离线SVG布局样例，不计远端服务验收。
