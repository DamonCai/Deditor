## 修改

- 阅读编辑的代码/图块预览在捕获阶段处理左键按下。嵌套 SVG 或 `foreignObject` 元素即使截断事件冒泡，图块也能先阻止浏览器建立原生文字选区，再沿用原有的整块选中或源码打开动作。
- 仅在可编辑的阅读视图中，渲染的图块预览禁止原生文字选择；图块仍可由编辑器整块选中，链接和媒体控件保留各自点击行为。只读内容仍可选择文字。
- 修正阅读编辑的隐藏选区样式优先级。ProseMirror 的 `NodeSelection` / `CellSelection` 会保留 DOM 选区供键盘和剪贴板使用，且标记 `.ProseMirror-hideselection`；Milkdown 的 `.milkdown .ProseMirror *::selection` 优先级更高，曾把这段本应隐藏的选区画成蓝色，包括图块之后的整个段落。现将原先仅保护表格的规则扩展到所有隐藏选区；普通正文选区仍显示。
- 实时预览使用独立的预览 DOM，不走这段节点视图鼠标处理；实测普通左键点图、点相邻段落没有残留选区，因此没有改它的选择语义。
