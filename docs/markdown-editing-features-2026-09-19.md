# Markdown 编辑功能补齐（2026-09-19）

## 范围

用户确认添加此前建议的四项：表格菜单补齐、明确复制粘贴格式、历史版本对比、斜杠快捷插入。另修复既有 H-TAB-01：末格 Tab 增行后的立即输入与增行合并撤销。

- 表格菜单新增选列、选表、上/下插行、左/右插列、清空内容；保留选行与删除。清空保留表格结构和对齐。表头上方插行时新行成为表头、原表头降为正文行，保存后仍是合法 GFM 表格。
- 阅读编辑工具栏新增复制粘贴菜单：Markdown、富文本、Excel TSV、纯文本粘贴。无文本选区复制全文，矩形选区复制所选单元格；TSV 无矩形选区时复制当前表格，表格外禁用。富文本默认对齐保留为未指定，显式对齐继续保留，避免往返后增加冒号。纯文本粘贴支持 Cmd/Ctrl+Shift+V，绕过 Markdown/HTML/TSV 解析；异步读取期间选区、正文或活动编辑器改变则拒绝应用。
- 历史版本增加“与当前内容对比”，复用现有左右差异视图，对比前刷新当前文档。支持切换版本、切回内容及原有可撤销恢复。
- 阅读编辑顶层普通段落行首输入 `/`，可按中英文关键词筛选表格、代码、Mermaid、PlantUML、任务、标题、列表、引用和分隔线；上下方向键选择、Enter 插入、Esc 取消。表格/列表/代码内与正文中间的斜杠不触发，组合输入不拦截。插入作为一次独立操作撤销。
