# 表格与图表五项交互调整（2026-09-19）

## 本次范围

只处理用户本次反馈：批量插入行列、水平/垂直对齐、从表格下方往上拖选、Mermaid/PlantUML 工具栏及删除、右键中英文。保留此前复制格式、历史对比、快速插入等未提交修改；未提交推送。

## 实施

- 表格右键及 Shift+F10 菜单增加数量输入（整数 1–100），四个方向按数量一次插入。整批是一次撤销；表头上方插入会生成新表头，原表头内容转为正文行。非法数量禁用插入。
- 对齐控件集中成两组：水平左/中/右作用于所选列（符合 GFM 列对齐语法），垂直顶/中/底作用于所选单元格。多格不同值不冒充统一选择。顶端为默认值。
- GFM 没有垂直对齐语法。中/底对齐用单元格首部隐藏注释 `<!-- deditor:valign=middle -->` / `bottom` 保存；阅读编辑和实时预览共同识别，富文本复制用标准 `vertical-align` 样式，纯文本不含注释。其他 Markdown 软件可忽略这些隐藏注释，但不保证恢复垂直对齐。
- 实际复现：从下方段落行首拖到表头，旧表格插件把跨段 TextSelection 收缩为表头单段。只替换跨表格边界时的选区规范化，保留原单元格手势、表格修复和整格选区处理。
- 图表工具栏使用淡底色、小型图标和名称选择入口、原尺寸三模式按钮、独立删除图标。名称可选中整块；删除支持一次撤销，三种模式及别名一致；只读隐藏删除入口。既有可拖动中线、等高分栏、模式切换稳定外框保留。
- 阅读正文、图表显示/源码及普通嵌入代码提供应用内右键菜单，跟随应用语言。嵌入源码的全选/复制/粘贴只作用于该源码编辑器。剪贴板失败不执行剪切删除；等待期间文档/选区/只读/活动状态改变时取消修改。嵌入源码粘贴、剪切有独立撤销边界。
- 实时预览复用应用已有右键组件，提供复制/全选；不再出现系统英文菜单。普通源码编辑器原有应用菜单保持。
