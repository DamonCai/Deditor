# XMind UI 与交互核对：第二批修复，整体一致性仍未通过

本次继续打开原版 XMind，并用本轮生成的归档核对联系、组织结构和自由主题。浏览器及独立 identifier 的 macOS 测试包使用同一批样例；未替换 `/Applications/DEditor.app`。以下是最新结果，后半部分保留第一批历史记录。

## 第二批修改

| 对象 | 实际发现 | 修复 |
| --- | --- | --- |
| 联系几何 | Cartesian controlPoints 是相对每个端点主题中心的偏移，原实现忽略该字段并固定从顶部连线 | 按向量计算曲线，按主题轮廓求交点；标签沿曲线中点；读取显式线色、线宽、箭头和文字样式；适合窗口考虑控制点范围 |
| 联系交互 | 无法选中、调控制柄、编辑和删除 | 支持选择、控制柄拖动、双击改名、Delete/Backspace 删除；每次拖动只生成一条历史；Esc/失焦取消拖动；保存前提交文字草稿 |
| 控制柄层级与焦点 | 小控制向量的柄被主题遮挡，结束输入后丢键盘焦点 | 联系绘制在主题上方；Enter/Esc 回到画布；真实 DOM 命中检查两个柄均命中自身 |
| 联系输入粘贴 | 真实浏览器 fill/paste 触发父画布粘贴，插入主题而非编辑联系 | 输入框的复制/粘贴保留原生行为；回归校验主题树不变、一次撤销恢复 |
| 自由主题方向 | 显式 map.unbalanced/right-number=0 仍被强制向右 | 独立自由主题保留自己的结构与左右分配；原版无显式字段的自由主题仍向右，不一概改向左 |
| 默认分支分配 | 两个主分支被平均分在左右，原版均在右边 | 无 right-number 时 1/2/3/4/6 个分支分别有 1/2/2/2/3 个在右边；显式值优先 |
| 组织结构连接 | 垂直结构无条件折线，忽略显式 curve | 默认中心分支曲线、下一层圆角折线；显式 curve/elbow/roundedElbow 按字段生效 |
| 备注入口 | 图标只能显示，无法打开备注 | 点击或 Enter/Space 选择图标所属主题、打开格式面板并聚焦备注 |
| 原生另存为 | macOS 使用 Markdown 第一过滤器，将测试归档另存为 `.xmind.md` | XMind 另存为专用 `.xmind` 过滤器，保持归档类型 |
| 文件类型切换白屏 | 上述后缀变化导致同一 Editor 从 XMind 分支切到文本，触发 React #310 | 文本编辑器 hooks 放入独立 TextEditor 组件，渲染类型切换不改变同一组件的 hook 次序；覆盖 XMind→文本→XMind、空图片→图片加载 |

联系操作依据 [XMind 官方说明](https://xmind.com/user-guide/relationship-new)；字段参考 [官方模型定义](https://github.com/xmindltd/xmind-model/blob/master/src/models/relationship.ts)。Cartesian 偏移语义由本轮原生控制点探针确认。默认曲线和未提供主题样式的颜色仍是近似，不能表述为完全还原。

## 第二批测试记录

轮 1 — 用例：联系控制向量、组织图上下分支、默认分支数量。
期望：字段对应路径，默认与显式结构规则分别生效。
实测：原版打开 2/3/4/6 分支探针，并核对控制点 `{200,-100}` 与 `{250,80}` 相对主题中心的位置；核心回归通过。
结果：已验证的规则通过；默认主题外观仍有差异。

轮 2 — 用例：中文粘贴、Enter/Esc、两个控制柄命中、720×480 深色窗口、控制点非法数值。
期望：输入不插入主题，取消不写文件，控制柄不被主题挡住。
实测：浏览器首轮发现粘贴误插入主题，修复后标题正确变化；Esc 后原标题保留；焦点返回画布；两个控制柄 elementFromPoint 均命中自身；无 NaN/Infinity 路径。
结果：修复后通过。

轮 3 — 用例：拖动→撤销、编辑→共享保存、删除联系→撤销、备注图标→选中与焦点。
期望：一个拖动对应一个历史事务，保存包含未离焦草稿，删除联系不删主题。
实测：模拟回归通过；真实浏览器 16 个可见主题保持不变，中文标题提交及删除/撤销通过，备注聚焦正确。
结果：通过。

轮 4 — 用例：macOS WKWebView 打开→联系改名→另存为，以及同一编辑器切换渲染类型。
期望：归档保存、其他内容不变、无白屏。
实测：首次原生另存为复现 `.xmind.md` 和 React #310；修复后原生另存为正确生成 `deditor-native-roundtrip.xmind`，画布正常；再次改名→Cmd+S→回读，除标题外全部 JSON 与压缩包其他文件逐项相同。原生控制柄从 (832,493) 拖到 (900,530) 后曲线更新，Cmd+Z 一次恢复，保存回读再次确认控制点与原始值一致。
结果：首轮失败，修复后原生复测通过。

最终自动化：39 项 XMind 核心测试、80 项交互回归通过；`npm run build`（由 Tauri 构建调用）通过，macOS `.app` 构建通过，`git diff --check` 通过。原生验证针对独立 identifier 的本地 release 测试包，不包括 Windows 和正式安装包替换。原有大 chunk 警告仍存在。

# 第一批历史记录

本轮检查当前源码、XMind 官方操作说明，并在真实 Chromium 浏览器中操作本轮生成的样例。没有读取用户现有文档、应用历史或持久化 state.json，也没有复用旧 .xmind 文件作为本轮测试输入。

原生窗口工具返回 Mac 已锁定，无法进入 XMind 桌面端。本轮没有原版与当前 DEditor 安装包的成对实测截图，不能把浏览器验证或单测通过表述为原版视觉一致性通过。未替换 /Applications 中的应用。

## 本轮修复

| 对象 | 复现问题 | 修改后的行为 | 证据 |
| --- | --- | --- | --- |
| 折叠控件 | 所有分支常驻减号；左侧、向上、向下结构都画在右边 | 展开状态在悬停或选中时显示；折叠状态常显后代数量；逻辑图与组织图按展开方向定位 | 浏览器上下结构截图、三方向回归 |
| 折叠状态 | 只保存在 Canvas 的 Set，切页重挂载即丢失 | 编辑文档写入 branch 字段；切页、保存回读和撤销重做保持一致；旧 XML 浏览仍只改视图 | 保存和历史回归 |
| 搜索 | 只搜 scene.nodes，找不到折叠分支的后代 | 搜索整张工作表，揭示匹配节点的祖先；搜索本身不写文档 | 浏览器搜索原本折叠的“撤销与重做”，撤销按钮仍禁用 |
| 大纲定位 | 选中隐藏节点后画布没有反应 | 展开其祖先，再将目标带进视口 | 搜索、折叠、大纲组合回归 |
| 新建与粘贴 | 工具栏给折叠主题添加子节点后，新增内容可能隐藏 | 文档新增/粘贴子节点时展开父主题，和编辑一起撤销 | 文档命令与既有新增、粘贴回归 |
| 标签 | 用分隔点拼成一段普通文字，丢掉独立标签外观 | 各标签使用独立浅灰圆角胶囊；长标签在自己的胶囊中换行，测量包含内边距 | 标签分离与长文本几何回归、浏览器截图 |
| 标题编辑 | 输入区尺寸固定；中文换行少算高度；相邻节点遮住草稿 | 编辑框随草稿增长；用真实 DOM 文字高度修正；编辑节点绘制在最上层；字体与节点一致 | 实测修复前 clientHeight 77 / scrollHeight 101 / scrollTop 23.5；修复后 101 / 101 / 0 |
| 右键菜单 | 以固定 260px 猜高度；菜单按钮获得焦点后 Esc 不关闭 | 以实际菜单尺寸避让边缘；短窗口可滚动；方向键、Home/End、Tab 导航，Esc 关闭并恢复画布焦点 | 720×480 右下角实测，键盘回归 |
| 拖动取消 | Esc 只关菜单，不清理拖动，放开鼠标仍可能移动主题 | Esc 清理拖动状态，后续 pointerup 不写文档 | 拖动—Esc—松开组合回归 |
| 小交互 | 双击折叠按钮可能触发标题编辑；中键平移会改变选择 | 折叠按钮隔离双击，中键平移保留选择；补 Cmd/Ctrl+/ | 事件路径检查及浏览器快捷键操作 |

折叠控件显示与数量规则参考 [XMind 官方折叠说明](https://xmind.com/user-guide/fold-unfold-subtopic-new)。标签采用独立胶囊的呈现，但本轮未与原生软件逐像素校准其圆角、字号和排列，不能声称完全一致。

## 已确认仍需处理的差异

以下来自当前实现的逐项检查，保留为未通过；没有以本轮修复覆盖它们。

| 优先级 | 对象 | 当前实现的问题 / 待核对范围 |
| --- | --- | --- |
| 高 | 联系线 | 固定从两个节点顶部起连，忽略 controlPoints；固定虚线、箭头与字号，标签按粗略中点放置。需要按原始字段与原生交互核对路径、端点、箭头和文字位置 |
| 高 | 自由主题 | 无显式结构的自由子树仍默认向右；需要用本轮新建并由原版保存的样例确认方向字段语义 |
| 高 | 组织结构连接 | 默认连接仍是折线；上/下结构的下划线叶节点与连接点需要继续对照，不能据本轮控件定位正确认定整图正确 |
| 高 | 多选与拖放 | 当前 pointer 仅记录一个 topic ID，拖动只处理单个节点；缺少插入同级位置提示与完整拖放目标反馈 |
| 高 | 备注与链接 | 图标仍占独立辅助行；不能像原版那样点击备注图标打开编辑或预览，链接目前只是格式面板中的文字 |
| 中 | 边界与概要 | 边界统一圆角矩形、透明填充与虚线；标题和概要括号样式覆盖不完整，缺少原生选择/编辑交互 |
| 中 | 形状与格式 | 只渲染椭圆、菱形、下划线和矩形类；其他形状回落为矩形；格式面板只修改首个选择主题，未表达多选混合值 |
| 中 | 快捷键 | 尚未完整对应 Shift+Enter 前插同级、父主题、全部折叠、原生方向导航等语义；本轮只补单主题折叠快捷键 |
| 中 | 鱼骨与时间轴 | 存在特定结构的近似算法；本轮没有新的原生同尺度证据，鱼骨镜像方向下的折叠控件也未验收 |
| 中 | 只读视图状态 | 旧 XML 可临时展开/折叠，但其只读视图覆盖不跨工作表缓存；本轮持久化验证针对可编辑 JSON 格式 |
| 中 | 超大标题 | 普通长中文、多行输入已验证；超过整个画布高度的草稿，以及极端缩放下的输入法候选位置仍需原生验证 |

## 三轮测试

轮 1 — 用例：折叠、切页、撤销重做、标准保存回读。
期望：隐藏数量正确，折叠跨页保留，撤销恢复原始数据，保存归档包含 folded。
实测：新回归全部通过；浏览器向下组织图按 Cmd+/ 后显示数字 2，两个子节点隐藏。
结果：通过。

轮 2 — 用例：左右/上下方向、分离标签、长中文与多行草稿、取消编辑。
期望：控件在展开侧，标签不合并，草稿全部可见且 Esc 不写入。
实测：三方向和标签回归通过；第一次浏览器验证发现中文高度估算不准与遮挡，继续修复后实测 clientHeight 与 scrollHeight 均为 101，scrollTop 为 0。
结果：修复后通过。单测首轮还因测试写错现有英文 aria-label 失败，修正测试选择器后通过。

轮 3 — 用例：隐藏节点搜索、大纲定位、720px 亮/暗界面、菜单键盘、拖动 Esc 与相邻保存/粘贴行为。
期望：搜索不写文件，菜单不裁切，取消不移动主题，既有编辑保存流程不回归。
实测：真实浏览器搜索、窄窗口上下结构和菜单检查通过；新增交互与完整回归通过。
结果：通过。原生 macOS / Windows 与 IME 未验证。

最终命令结果：`npm run test:xmind` 33 项通过；`npm run test:regression` 75 项通过、0 失败；`npm run build` 通过（现有大 chunk 提示仍在）；`git diff --check` 通过。
