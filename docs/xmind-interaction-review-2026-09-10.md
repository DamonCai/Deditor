# XMind UI 与交互核对：第五批结构校准与最终原生复测

本节覆盖原版默认思维导图、左右逻辑图、上下组织图、括号图、左右头鱼骨图和水平时间轴。全部输入为本轮新生成的样例；原版与 DEditor 使用同一组主题数据。原版窗口截图存在应用内缩放与截图尺度差异，因此先归一化中心框尺寸，再比较间距、连接点、分支次序，不按裸屏幕像素硬改字号。

## 本批发现与修复

- 中心主题和主主题上下内边距偏小；修正后默认模型高度分别为 78 和 47.2。
- 1–4 分支象限与原版不符；单侧单分支采用上/下象限，双分支避开中心框。5–6 分支保留中间对齐及左侧倒序。
- 非对称子树按总包围盒居中导致连线接点漂移；改为按首尾真实接点居中，下划线使用底边接点。
- 逻辑图错误复用了思维导图的短曲线；左右逻辑图改为侧边出线、100 模型单位主层间隔。
- 组织图层间距与子主题横间距不符；主层间隔为 100，后代层间隔为 24，后代兄弟间隔为 6，并按子主题实际中心对齐。
- 括号结构没有向后代继承，且括号前多画直线；补结构继承及显式覆盖，去掉多余直线，校准括号跨度和层间距。
- 鱼骨明细间隔过大，右头折叠入口在错误一侧；改为紧凑明细排列，根部留白与原版一致，右头折叠按钮移至轴线侧，并提供明确的右头结构选项。原因主题的控件沿斜骨定位；空分支/折叠分支分别留 50/70 模型单位，上下两侧独立避让，避免折叠后被另一侧撑宽。
- 水平时间轴错误地把主主题放在轴线两侧；重写为主主题在同一轴线上依次排列，明细交替上下展开，以圆角竖干连接。大标题及深层子树按实际重叠的垂直区间避让，上下两侧可交错排列；长标题不再无故推远下一主主题。其他时间轴变体仍保留近似提示。
- 真实 Cmd+O 选择框将 .xmind 置灰：文件过滤表缺少 XMind。已补显式扩展名，新增回归验证二进制加载与取消行为；原生新包已确认完整路径选择后 Open 可用，正常进入八工作表导图。

  结果：✅ 保存互通；最终构建已重启，原生长标题保持主轴节奏；鼠标点击鱼骨斜骨控件，保存后 branch=folded，另外七张工作表不变；Cmd+Z → Cmd+S 后整个八工作表文档与保存前逐项相等。

# XMind UI 与交互核对：第四批原生复测

最新状态以本节为准，下方保留前三批历史记录。解锁后已继续原生核对，未把之前的锁屏阻断记作通过。

## 本批发现与修复

- 自由主题的画布采用 14 号字，但格式面板按普通主主题显示 18 号字及灰色填充。面板现按主题类型和分支继承解析样式，覆盖自由主题、批注、概要及后代。
- 点击格式面板删除边界后，Cmd+Z 因焦点离开画布而失效，工具栏撤销仍有效。增加当前 XMind 标签的窗口级撤销/重做处理；输入框保留文字编辑撤销；画布事件不会重复执行。
- 用原版分别打开 3、4、5、6 个主主题的同一归档，确认左侧顺序为从下向上；三主主题情况下左侧单主题位于中心下方。修正这一象限位置，单向逻辑图仍保持居中。

- 原版互通复测暴露概要默认外观错误：概要主题现在采用原版确认的 14 号字、白字、`#00897B` 圆角框；边界填充及概要线使用绿色，边界不透明度 20%。主题和分组显式样式仍优先，面板与画布共享默认/继承解析。
- 边界标题原先只是灰色裸文字；现补绿色底白字标签、14 号字及居中换行，标题高度与宽度纳入场景边界和分支避让。亮色 720px 和深色长中文标题已实测；四方向长标题与概要组合的几何回归通过。
- 大纲遗漏概要和批注，导致这些主题无法从大纲定位；现完整列出并支持选中定位。

## 本批测试记录
