# Markdown 预览排版验证

修改范围：`src/styles.css` 中的预览样式。调整正文颜色与行距、标题间距、链接焦点、行内代码、代码块、引用、列表、表格和键帽；适配亮暗主题及窄分栏。阅读模式保留可用宽度，修复超宽表格突破预览容器的问题。没有修改解析器、源文件内容、导出样式或原生后端。

使用临时页面挂载实际 `Preview` 组件、Zustand store 和 Markdown 渲染器，检查完成后移除临时页面。

自动检查：`npm run test:regression` 为 46 passed、0 failed；`npm run build` 通过，仍有既有的大 chunk 提示；`git diff --check` 通过。

验证范围为浏览器中的实际 React 组件，未验证 macOS/Windows 安装包、原生打印与导出、本地图片 IPC，以及编辑器与预览的双向滚动联动。
