# 新建编辑器窗口（2026-09-21）

根据用户提供的 Dock 菜单截图增加“新建窗口”。不引入终端 Profile 概念。

## 实现

- macOS Dock 新增“新建窗口 / New Window”，通过 AppKit 的 `applicationDockMenu:` 提供菜单；保留 Tauri 原有 application delegate，仅增加它未实现的可选 selector。
- 原生文件菜单和命令面板提供同一功能，快捷键 Cmd/Ctrl+Shift+N，可在设置中禁用该快捷键。
- 新窗口从空白文档开始，继承来源窗口已保存的外观与编辑偏好，不复制标签、工作区和展开目录。
- 每个窗口独立维护标签、撤销、状态及恢复文件；新窗口不能读取或清理主窗口的旧 localStorage 会话。
- 原生菜单、系统文件打开和拖放按目标窗口分发。打印、全屏原生按钮和标题也按窗口处理；macOS 窗口菜单显示可切换的窗口列表。
- 关闭/退出前刷新文档和恢复状态，等待写盘完成。写盘失败时保持应用打开并显示错误；退出请求会取消，其他窗口恢复常规持久化。
- 主窗口保留原有关闭后恢复行为。辅助窗口关闭时，如果没有未保存编辑，移除该窗口的恢复快照；存在未保存编辑则保留，供下次启动恢复。整体退出时保留所有仍打开的窗口。
- 不替换日常安装应用；后续按用户要求提交到本地仓库，不推送。

## 四轮验证

轮 1 — 主路径：新建窗口、空白文档、独立输入与保存。
- 期望：文件菜单/快捷键创建独立窗口，保存仅作用于当前窗口。
- 实测：macOS 隔离包文件菜单和 Cmd+Shift+N 可创建空白窗口；A、B 分别输入中文文字，B 保存时 A 草稿保持原样。两个样例最终保存内容逐字节一致。
- 结果：上述范围通过。

轮 2 — 边界：空会话、中文、偏好继承、旧存储与恢复文件。
- 期望：新窗口不带入其他窗口正文；恢复不串窗口。
- 实测：7 组关闭持久化测试通过，包含新增的辅助窗口旧存储隔离、空快照继承暗色中文偏好、关闭暂停/取消后恢复持久化。3 项 Rust 测试覆盖快照分离、过滤暂存/无效文件及新窗口偏好清理。原生中文暗色新窗口为 0 字符，亮色英文窗口不受影响。
- 结果：通过。

轮 3 — 组合与错误：快速重复关闭、慢写盘、失败重试、关闭一个窗口、整体退出和重新启动。
- 期望：关闭等待写盘；错误不导致退出；其他窗口保持可用。
- 实测：5 项窗口生命周期专项通过。原生关闭空白及已保存的辅助窗口后，其他窗口仍可编辑；相应恢复文件被移除。退出并重新启动后，A 的自建未保存中文草稿恢复，随后逐键输入并保存成功。原生窗口菜单可列出多个窗口。
- 结果：上述范围通过。
