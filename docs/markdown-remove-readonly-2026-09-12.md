# 移除 Markdown 只读模式（2026-09-12）

用户明确要求删除独立的“只读”模式。Markdown 现在只有“编辑、实时预览、阅读编辑”三个入口；HTML 的“编辑、实时预览、阅读”和 XMind 专用模式保留。

## 实施

- 删除应用模式联合类型、模式选择按钮、中英文标签、宿主路由和工具条／图片设置中的只读分支。
- 历史持久化数据中的 `markdownMode: "read"` 恢复为 `visual`，下一次保存写入新值；草稿、原文、撤销和 HTML 预览设置保留。
- 阅读编辑与实时预览继续使用共享展示层，未修改字体或正文样式。底层编辑组件的通用只读防护及隔离测试保留，应用不再提供该模式入口。
- README 已更新为三种模式。此前文档中的“只读模式”描述为历史实现／测试记录，不是后续要求。
