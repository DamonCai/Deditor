# 表格选列相邻空白误高亮（2026-09-13）

范围：用户截图中的表格选列后，相邻单元格下方空白出现蓝块。只修改阅读编辑表格的隐藏原生选区样式，没有改动选区计算、内容、共享 Preview 或 XMind。本任务未提交推送；期间外部提交包含了本批修改，接续应重查 Git。

## 原因与修复

隔离旧包 `DEditor Reading Feedback Review.app` 中，用本次自建三列表格实际复现：中列为三项列表，左右为短正文，形成较高空白。纵向选择中列两格时，左侧末格下方同时出现深蓝块。复制后粘贴到源码，实际只包含中列六项目标，没有左右列文字。

ProseMirror 的 `CellSelection` 保留原生 DOM 范围，用 `ProseMirror-hideselection` 隐藏文字高亮。Crepe 的 `.milkdown .ProseMirror *::selection` 覆盖了隐藏规则；WebKit 将原生范围的高亮画进前一单元格空白。Chromium 的同结构拖选没有额外蓝块，不能替代原生复现。

`markdown-visual.css` 在阅读表格范围内恢复隐藏规则（含 Firefox 伪元素），保留单元格覆盖层和 DOM 范围；正常文字选择退出隐藏状态后仍显示原主题色。不清除 DOM selection，不改变复制或键盘行为。
