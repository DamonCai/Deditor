# 1.0.3 macOS 阅读查找修复与长文优化

任务来源：用户在当前会话报告阅读编辑 Command+F 白屏，并明确要求修复后本地重装、推送代码及重新上传 DMG。此次交付合并此前长文性能改动和已有的查找栏高度修复。

## 问题与修复

查找控件由一个空的 CodeMirror 视图承载。全局编辑器高度 100% 使它在独立 WebKit 文档中撑满区域，正文视口被挤掉。将这个仅承载控件的视图设为内容高度，正文与查找栏可以同时显示。没有改变正文内容或搜索模型。

前一次隔离性能安装包遗漏了工作区的 SearchPanel 修复。本次核对全部十个产品源码与发布快照逐字节相同，并移除本地性能诊断导入，确认最终 JS 不含 MD_OPEN_PROFILE。

长文共享语法树、按视口显示普通正文/表格/公式、惰性代码高亮和视图重建锚点一并保留。性能与完整模型验证见 [长文记录](markdown-shared-model-2026-11-05.md)。其中 603–900 ms 为上一轮同批报告的诊断安装包样本，本次移除诊断后未重复计时，不冒充本次全批耗时。
