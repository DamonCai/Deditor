# XMind 跨文件图片与联系复制修复

性能优化后继续处理待办审计确认的两项缺口。新增版本化剪贴板载荷，携带所选主题实际引用的图片/附件字节及集合内部的联系；原有主题数组和纯文本格式继续保留。只复制所选子树一次，使用整组 ID 映射修复内部链接、概要引用和联系端点。集合外的联系不复制，集合外内部链接在同文档保留、跨文档移除，防止碰巧跳到目标文档同名 ID；外部网址保留。

目标同名图片与源字节一致时复用，不同时生成新资源名并改写引用，保护目标原图。ZIP 新成员追加保留原有压缩流，manifest 合并不覆盖其他字段。粘贴作为单个历史版本，资源文档按引用与主题一起撤销/重做，不为普通标题编辑复制附件。异常载荷、缺资源、非法路径和无效联系在发布前拒绝，错误在原有操作失败横幅显示。
