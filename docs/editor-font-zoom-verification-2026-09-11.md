# 编辑区单文件字号缩放（2026-09-11）

最终行为遵循用户补充：Cmd/Ctrl + 滚轮只临时缩放当前打开的文件。切换标签保留各自字号，同文件分屏同步；关闭后重新打开恢复设置中的默认字号。关闭历史及磁盘状态均不保存临时缩放。设置面板修改默认字号；Markdown 工具条的字号按钮调整当前文件。此前全局缩放和分别持久化当前/基准字号的方案已被此行为替代。

在文本编辑器滚动区（含行号栏）监听非 passive wheel 事件，向上放大、向下缩小；普通滚动、Shift/Alt组合及纯水平滚动保持原行为。按像素/行/页单位归一化，累计细小滚动，单次最多改变3px，范围10–28px。快捷键设置可禁用；监听器随编辑器卸载清理，不绑定预览、图片或XMind。

底部提示显示当前字号、“恢复为 Npx”及设置入口。恢复仅清除当前文件临时字号，返回编辑焦点；恢复目标为设置中的默认字号。连续缩放刷新提示，空闲4秒收起，悬停或聚焦暂停计时；Escape关闭并返回编辑器。临时字号存于打开的Tab，序列化和关闭记录均显式排除。兼容此前带editorBaseFontSize的状态：只迁移其默认字号，不恢复全局临时缩放。
