# 实时预览与阅读编辑的列表显示统一（2026-09-12）

本次根据用户的两张截图，仅处理列表显示差异，并按用户授权安排三个 agent 独立检查交互、增强呈现检查器和评审样式边界。未提交推送；保护同时进行的 Markdown 操作验收修改。

## 原因与修复

此前两端已经共用 `MarkdownDocumentSurface` 的主题、字号和共享样式入口，但正文仍分别由 markdown-it 和 ProseMirror 生成。不能将这一状态称为整篇正文已使用同一个渲染组件。

- 预览任务框使用浏览器禁用 input，阅读编辑使用 Milkdown 的 SVG，导致颜色、实际绘制大小、圆角不同。现将勾选图案、尺寸、边框、背景和透明度集中到 `preview.css`，两种交互宿主使用同一套显示规则。
- 阅读编辑的无序列表曾用文字字符仿制圆点。现与预览一样使用浏览器原生列表标记，层级类型由共享样式指定。
- 阅读编辑的任务项采用 flex，使任务框后的整个子列表一起缩进。现让列表内容回到普通块流，任务框只占首行相应空间，子列表按共享缩进排版。
- 去除为旧 flex 结构添加的嵌套列表尾部边距减法。边界复测曾捕获有序项后偏移 +2.84375px、多段任务后偏移 −2.859375px；修正后专项页 24 个列表项相对横纵坐标、宽高全部一致。

产品改动仅在 `src/preview.css` 和 `src/components/markdown-visual.css`。保留原有编辑器实例、文档模型和任务点击/键盘事件。
