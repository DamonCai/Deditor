# 阅读编辑表格删除列（2026-09-14）

范围：在表格右键菜单及 Shift+F10 菜单增加“删除列”，复用现有中英文文案。当前单元格删除所在列，矩形选区删除覆盖的列，最后一列或全部列删除时移除表格。一次操作单独形成撤销边界。复用 ProseMirror 的列删除命令，保留剩余单元格内容、格式和对齐；补齐 CellSelection 的键盘菜单定位。

轮 1 — 基础用例：首列、中列、末列，以及右键目标与旧光标不同。

- 期望：只删除目标列，保留其余行列、格式、对齐和表外正文。
- 实测：新增 F00col1 通过，粗体/行内代码与三种对齐保留；保存模拟、一次撤销、重做及重新挂载通过。

轮 2 — 边界与组合：反向多列选区、Shift+F10、单列、仅表头、全部列、只读及表外调用。

- 期望：多列一次删除，一次撤销恢复；删除全部列移除表格，只读/表外无变化。
- 实测：F00col2/F00col3 通过；完整 22 组表格测试、test:regression、生产 build 通过。构建保留既有大 chunk 提示。

轮 3 — 实际浏览器：使用自建 `tests/markdown-column-selection-review.html`。
