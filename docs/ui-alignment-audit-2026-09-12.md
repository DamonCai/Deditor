# 控件垂直对齐横向核对（2026-09-12）

用户反馈 Markdown 字号、导出、写作设置不在同一水平线，随后要求检查其他区域。本次只处理应用控件对齐，保护工作区中同时进行的 Markdown / XMind 改动；未提交、未推送。

## 发现与修复

- 前一轮：写作设置外层为普通行内排版，按钮中心比外层低 1.5px；改用 flex 外层，并为导出和写作设置统一 24px 高、18px 行高、图标与文字居中。
- 本轮新增：`.md-toolbar-views` 的普通块外层包含 inline-flex 分段控件，外层高 25.5px、控件高 24px；在同排宽窗口中，外层中心为 53.75px，控件中心为 54.5px，偏下 0.75px。外层改为 flex / align-items:center，移除基线留白。修复后外层与控件均高 24px，同排字号、导出、写作设置、模式切换中心一致。
- JSON 主按钮与 ghost 按钮因边框产生 2px 高度差，但内部内容与相邻按钮中心一致，没有将这种尺寸差误判为错位或扩大修改范围。
