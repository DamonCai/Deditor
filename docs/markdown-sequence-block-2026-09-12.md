# 第三轮连续操作：特殊块与图片（2026-09-12）

本轮先依据漏检复盘定义用户预期，再执行以下 8 条高风险操作链。仅自建数据；模型/组件操作与真实浏览器鼠标键盘分别记录。当前工作区已有大量并行修改，本路不改代码块、任务、文档层、样式总表、总清单或包配置。

| 链 | 操作生成的中间状态 | 用户预期 |
| --- | --- | --- |
| S1 | 插入 HTML/详情 → 打开源码 → 全选清空 → Esc → 输入正文 | 不残留吞键的空特殊块，正文在当前位置，邻文保留，撤销重做恢复对应状态 |
| S2 | 插入 HTML → 点击源码 → 修改 → 点击邻段 → 再点块 | 点击邻段后光标留在邻段，块恢复静态呈现；重新进入可继续编辑已改内容 |
| S3 | 清空保留块 → ↑/↓ 退出 → 输入；邻段为空或相邻图片 | 正文在选择的边界，图片与相邻段保留，撤销后可继续输入 |
| S4 | 保留块 Esc → Delete → Undo → Redo → Undo → 接着输入 | 删除和恢复准确；最终按键作用于恢复后的明确编辑位置，没有隐藏编辑器抢焦点 |
| S5 | 插入带标题图片 → 清空标题 → 点击外部 → 删除 → 撤销 → 继续输入 | 清空被保存且图片仍在；删图撤销完整恢复，失焦控件不改变正文高度 |
| S6 | 插图到空段/相邻特殊块 → 前后方向键 → 输入 → 撤销重做 → 再按键 | 图片不被意外替换，正文位于选定前后边界，历史后的焦点可继续操作 |
| S7 | 创建公式 → 全选清空 → Esc/方向键退出 → 输入 → 撤销重做 | 空公式能够退出，公式外正文可编辑，历史不吞下一个按键；本路只验不改 codeView |
| S8 | 自建长页中滚到 HTML/详情 → 点击编辑 → 改文 → 点击邻段 | 点击与失焦后焦点正确、源码保留，记录高度和滚动；不把静态展示指标当作交互验收 |

## 最终结果

**8 条预定连续链已检查，9 组独立组件专项通过，去重后本路发现并修复 4 类问题。** 测试数量不是全量可用性结论。另复跑原图片 8 组与块边界 15 组回归，均通过；TypeScript 与差异格式检查通过。

| 问题 | 修复前实际证据 | 修复 |
| --- | --- | --- |
| 离散操作误合并撤销 | 浏览器新插图→立即删除→Undo仍无图；组件在插入/清空/退出/删图链多次回到过早状态；标题清空再删除Undo还带回旧标题 | 插入命令完成后建立边界；raw进入/显式退出、图片字段焦点进出建立边界。保留普通连续输入的合组，方向键新建空段与紧随正文仍按原边界处理 |
| 保留块失焦后仍是源码外观 | HTML编辑后实际点After，焦点为正文，但rawEditors=1、previewHidden=true | focusout后等待当前更新结束，确认焦点在块外才关闭内嵌编辑器；不把焦点抢回块里 |
| 图片标题延迟提交干扰历史 | 标题真实Ctrl+A/Backspace后输入框已空，源文仍有title；上游使用1000ms定时写入，组件即时撤销断言失败 | wrapper接管标题input/blur，即时提交，撤销刷新已聚焦控件，避免迟到定时更新重新写入。经过1100ms等待及blur的组件链通过，浏览器即时清空/撤销/等待/blur也通过 |
| 历史恢复丢失整块选区类型 | raw Esc→Delete→Undo→Redo→Undo后不是NodeSelection；实际ArrowDown+c进入HTML尾部，未到块后正文 | 历史保存selection.toJSON，恢复时用Selection.fromJSON；旧无JSON历史及未知selection类型均保留原位置回退。未改文档层和历史数据结构优化 |

## 连续链证据对应

- S1：自建插入HTML/详情，源码全选删空、Esc、输入a、Undo、Redo、继续b。实际结果为块处正文ab，Before/After保留；撤销a后恢复空中间状态。
- S2：HTML新建后编辑、实际点击邻段，rawEditors从1变0，previewHidden=false；邻段输入仍在邻段，重新点编辑可读到原修改。组件用外部按钮真实focus事件触发失焦，再构造邻段选区；真实鼠标位置由浏览器证据承担。
- S3：图片旁HTML清空后↓退出继续输入，图片、此前中间正文、邻段均保留。组件另覆盖↑与↓变体。
- S4：Esc整块选择、Delete、Undo、Redo、Undo后浏览器呈`ProseMirror-selectednode`且没有raw源码编辑器；随后↓+c得到cAfter，HTML保留。旧无JSON及未知选择类型回退有独立组。
- S5：新插图片的即时删除撤销、图片标题真实键盘清空即时写入、聚焦撤销恢复title、等待后失焦不覆盖撤销、再次清空后删图撤销均核对。图片选中/失焦时同一块高度140px，未新增常显控件。
- S6：用户操作插入相邻图片+HTML，再从HTML前边界创建中间正文m，Undo/Redo后继续n，得到图片与HTML之间的mn。
- S7：创建块公式、全选清空、↓退出、输入a、Undo/Redo后继续b，得到空公式之后的abAfter；本路没有改codeView，结论只针对记录的固定快照。
- S8：45段自建长页，先滚到末段再记录位置。HTML块内插入a、点击邻段后scrollTop仍1527、块top仍383.71875px、高仍29.59375px；源码为`<div>generated long blocka</div>`，raw编辑器0个，焦点正文。另一次在HTML标签外追加a使渲染自然增加一行，未误报成焦点布局bug。
