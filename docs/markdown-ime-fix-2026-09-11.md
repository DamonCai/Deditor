组词时可见内部光标占位图，但浏览器核对该元素为 inline、margin=0、height=0，没有证据认定图片样式为根因，未据此修改共享样式。具体是 WebKit 自带选区定位还是编辑器滚动路径触发，尚未完整分离；本次保护针对已复现的组词期间可见光标被重新定位。

## 实现

`compositionViewport.ts` 仅挂在 Markdown 阅读编辑实例。compositionstart 记录文章滚动位置；组词及确认的两个渲染帧内使用 DOM 光标坐标（组词文字可能领先于模型），若仍在原可视区则保持滚动位置；越界时只滚动必要距离。接管这段时间的 ProseMirror 自动定位，并在原生 scroll/input/selectionchange 后按帧校正。

滚轮、触控滚动、新的鼠标选区优先，立即解除保护。确认结束后释放；卸载时清除全部监听和动画帧。不改 Markdown 文本、光标选区、输入法候选内容或 HTML/XMind 路径。
