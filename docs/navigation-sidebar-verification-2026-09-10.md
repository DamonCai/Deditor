# 悬浮目录与多文件夹侧栏验证

## 最终交互

右侧采用用户确认的交互：默认细线导航、悬停展开、移开后延迟 180ms 收起，可以固定展开。悬浮状态不改变正文宽度。键盘 Enter 打开后焦点进入固定按钮，Esc 关闭浮层并返回细线入口，焦点留在目录内时不会因鼠标移开关闭。固定状态写入 `tocPinned`；旧 `tocVisible` 不视为固定，新交互首次默认收起。

参考了[钉钉官方对收起式文档布局的介绍](https://page.dingtalk.com/wow/dingtalk/default/dingtalk/ImasfynJzGJ0114?dd_mini_app_id=5000000004997171)。悬停、移开收起、固定这一具体交互由用户在本次对话中确认。

左侧去除工作区根目录的整行重底色，使用轻分隔与留白分组；根目录、文件行均支持键盘操作，使用统一箭头和 28px 文件行。同名根文件夹显示父路径辅助区分，长名称保留完整 title。每个分组提供省略号操作入口，复用原右键菜单；文件选择与对比标记仍各自保留。

## 验证

临时页面使用实际 Preview / FileTree / store。文件树 IPC 使用虚构文件夹的只读模拟数据，未操作用户真实文件。

| 轮次 | 预期 | 实测 |
| --- | --- | --- |
| 1：悬浮 | 移入展开，移开收起，正文不重排 | 进入导航区域后 `expanded=true, pinned=false`，正文宽度保持 673px；移开后自动收起，宽度仍为 673px |
| 2：固定与键盘 | 固定后离开不收起；Enter/Esc 的焦点合理 | 固定后离开仍展开，桌面正文宽度变为 473px；Enter 打开后焦点在“固定目录”，Esc 后返回细线按钮；旧显示状态不误恢复为固定，新的 true/false 固定状态可恢复 |
| 3：文件夹 | 独立折叠、同名区分、文件选中、嵌套加载和菜单可用 | 4 组工作区，同名“文档”显示 `/Work` 与 `/Personal`；根目录折叠不改变其他分组或 activeId；重新展开保留选中文件；Enter 展开 assets 出现子文件；省略号键盘入口打开原有操作菜单，Esc 可关闭 |
| 4：主题与边界 | 亮暗主题协调，720px 不横向溢出，长目录可滚动 | 720px 下文件树宽度与 scrollWidth 都为 248px，正文两者都为 417px；长文件名省略；86 项目录面板高 696px，内部可视高 646px、总高 3135px；最后标题可定位，20 条缩略线中恰有 1 条标识当前章节；无标题显示“无标题” |

`npm run test:regression`：48 passed、0 failed，含新增的固定状态迁移和同名工作区独立折叠测试。`npm run build` 通过；仍有既有的大 chunk 警告。`git diff --check` 通过。

范围：实际浏览器组件、布局、键盘与鼠标事件。未验证 macOS/Windows 安装包、真实原生文件读写与原生菜单。
