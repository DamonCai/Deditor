# 编辑器、XMind 与 Markdown 工具栏排查（2026-09-10）

基线：`9cb23e1`。本轮修改源码并完成前端生产构建，没有重新打包或安装 macOS / Windows 应用。检查重点为 XMind 文档编辑/渲染、Markdown 工具栏、外部文件监测；已有完整回归同时覆盖保存、另存、关闭、编辑器保留、查找、文件树、对话框等路径。这是一次有边界的排查，不代表整个应用没有其它 bug。

## 已修复的问题

| 问题 | 触发与影响 | 修复 |
| --- | --- | --- |
| XMind 拖放目标被遮挡 | 被拖动的 SVG 节点跟随鼠标，`elementFromPoint` 命中它自身，落到另一个主题时仍可能变成自由主题 | 拖动预览不参与命中测试；浏览器实测 `local` 拖到 `read` 后父主题变为 `read`，单测验证撤销与自由主题标识 |
| 复制父子节点导致内容重复 | 全选/同时选择祖先和后代，复制时每个选中节点都携带自己的子树 | 只复制选中子树的根，后代只出现一次 |
| 多节点粘贴不原子 | 每个节点单独修改、打包、入撤销历史；后面的剪贴板内容无效时前面的节点已经写入 | 全部校验后执行一个 paste 命令，只发布一次、一次撤销整个粘贴；嵌套重复 ID 被拒绝 |
| 外部变更读取失败后漏更新 | 读取前先确认 mtime，临时读取失败后，同一个 mtime 不会重试 | 成功读取并验证标签仍有效后才确认 mtime |
| 外部文件监测并发/过期读取 | 3 秒轮询可重叠；读取期间本地保存或关闭重开，旧内容可能覆盖新状态 | 串行轮询；校验标签 ID、保存内容；清除已关闭文件的 mtime 缓存 |

## 性能结果与边界

相同机器、1001 节点样例；下列数字是本轮局部基准观测，不是原生应用 FPS 或完整打开文件耗时。

| 测量项 | 修改前 | 修改后 | 说明 |
| --- | ---: | ---: | --- |
| 缩放时 React 更新中位耗时 | 23.96 ms | 约 0.13–0.15 ms | jsdom + React Profiler，连续 8 次缩放；缓存 SVG 内容，平移/缩放只更新 viewBox；依旧保留所有 1001 节点 |
| 10 次布局中位总耗时 | 37.61 ms | 21.68 ms | `npm run perf:xmind`，默认文字估算器；分支索引、连接端点查找改为 Map |
| 10 次归档修改中位总耗时 | 3.67 ms | 3.83 ms | 无明显改善，本轮未改归档实现 |

归档已经通过 `replaceArchiveEntry` 复用附件的压缩字节，并没有每次重新压缩所有附件。每次修改仍需序列化工作表、复制输出 ZIP、生成 base64；本轮减少了多节点粘贴时重复执行这些步骤的次数。

现有归档基准的“1 MB 附件”是重复字节，压缩包实际约 6 KB，不能据此宣称大型图片附件文件也能达到相同速度。后续优化优先级：真实大附件及深层导图基准 → 文字测量缓存 → 不可见节点裁剪 → 文档编辑的结构共享与增量序列化。当前平移缩放仍需浏览器绘制全部 SVG；节点拖动、选中和编辑会更新场景内容。

## 与原版 XMind 的接近程度

**结论：已经具备常用导图的基本表现与编辑能力，但目前不能称为与原版非常接近，也不能给出可靠的相似度百分比。**

官方文档展示了多种结构和关系线/边界/概要的独立样式能力：[Topic](https://xmind.com/user-guide/topic-editing-new)、[Style](https://xmind.com/user-guide/style-new)。结合当前源码，有以下明确差距：

| 项目 | 当前实现 | 影响 |
| --- | --- | --- |
| 关系线 | 固定三次曲线路径、虚线与末端箭头；未使用原文件控制点；端点仅查主题节点 | 原版手工调整曲线、箭头样式，以及连接边界的关系不能准确呈现 |
| 标签 | `labels.join(" · ")` 后折行 | 丢失独立标签胶囊的视觉分组 |
| 结构 | 矩阵等未实现专属布局；时间轴近似；鱼骨结构标识未严格区分方向 | 特殊结构与原版差距明显，不能以“节点都存在”视为一致 |
| 边界/概要 | 边界统一圆角矩形及固定虚线，概要使用简化括号 | 原文件样式不能完整还原 |
| 折叠控件 | 所有非叶子主题持续显示按钮，统一放在右侧 | 左向结构的控件位置和原版交互观感有差距 |
| 搜索 | 搜索范围是当前可见场景节点 | 折叠分支内的主题暂时无法搜到 |

已有原生对照记录见 `xmind-original-audit-2026-09-10.md` 和 `xmind-quality-detail-audit-2026-09-10.md`。其中一些旧问题（如分支颜色继承、圆角连线、批注尾巴）已有后续修复，本轮没有把旧截图当作当前版本截图。本轮浏览器验证了当前组件的布局与实际拖动，没有重新做同文件、同工作表、同缩放的原生 XMind 成对截图，因此不宣布视觉一致性验收通过。

## Markdown 工具栏新增 7 类操作

- 下划线：`<u>…</u>`。
- 上标 / 下标：`<sup>…</sup>`、`<sub>…</sub>`。
- 折叠内容块：`<details>` + `<summary>`，保留选区并补齐 Markdown 空行。
- Mermaid 时序图、甘特图模板。
- PlantUML 模板（工具提示明确预览需要联网）。

复用已有预览，不新增依赖；补齐中英文文案。文字包裹支持再次点击取消；每个动作可单独撤销；阅读模式沿用禁用规则。暂未增加脚注或自动目录按钮，因为需要先补相应解析/更新逻辑，不能只插入一段预览不支持的语法。

## 后续：图标说明显示延迟

原 HTML title / SVG title 的提示延迟由 WebView 控制。改为一个挂载在入口的 Tooltip 浮层，通过事件代理服务工具栏按钮、XMind 节点标记、缩放和折叠图标，无延迟定时器；移出、点击、滚动、Esc、失焦和目标移除时关闭。浮层不参与鼠标命中，保留无障碍名称并关联 aria-describedby。

通用回归增至 66 项全部通过，生产构建通过。浏览器验证了键盘聚焦即显示、SVG 图标说明、右下角边缘自动避让、pointer-events:none 及 Esc 关闭；鼠标移入移出、禁用按钮、点击和异步隐藏由 DOM 事件回归覆盖。本次仍未更新已安装应用。

## 后续：Mermaid / PlantUML 系列下拉菜单

工具栏将分散的流程图、时序图、甘特图和 PlantUML 按钮整合成 Mermaid / PlantUML 两个独立入口，采用与字体颜色相同的按钮加下拉箭头、portal 浮层交互。面板使用两列图标和名称，点击一项立即插入可编辑模板，保持原文选区定位并选中模板中的可修改内容。

| 系列 | 本轮提供的 11 种模板 |
| --- | --- |
| Mermaid | 流程图、时序图、类图、状态图、实体关系图、甘特图、饼图、思维导图、时间线、用户旅程、Git 分支图 |
| PlantUML | 时序图、活动图、类图、用例图、组件图、部署图、状态图、对象图、思维导图、工作分解图、甘特图 |

能力分类参考 [Mermaid 语法说明](https://mermaid.js.org/intro/syntax-reference.html) 和 [PlantUML 官方文档](https://plantuml.com/)。这里是常用模板入口，不是穷举两种语言全部语法，也不是可视化图表编辑器。

交互：方向键/Home/End 选择，Enter 插入，Esc 取消并恢复按钮焦点，Tab 退出菜单；点击外部、滚动外部、切换文档或进入阅读模式关闭面板。切换系列只保留一个面板。打开菜单不修改文档；插入可单次撤销；文档在菜单打开后变化则拒绝把旧选区写回。PlantUML 面板注明联网预览及内容发送至 PlantUML 服务。

验证：69 项通用回归通过；22 个模板逐项验证代码围栏、原文前后内容保留、选中占位文本和单次撤销。11 个 Mermaid 模板通过当前安装版本解析，并在真实预览生成 11 个 SVG、0 个错误；11 个 PlantUML 模板通过现有公共渲染端点返回 HTTP 200 和有效 SVG、0 个语法错误，仅使用本轮生成的示例内容。浏览器验收了亮/暗主题、720px 工具栏（clientWidth=scrollWidth=720）、菜单宽度 320px 且不越界。生产构建通过，保留原有 chunk 大小提示；安装版未替换。

浏览器另行验证：PlantUML 菜单用 End、←、Enter 选择工作分解图，菜单关闭、焦点回编辑器，实际预览生成 SVG，无错误。
