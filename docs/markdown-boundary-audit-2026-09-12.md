# 阅读编辑边界与空内容补查（2026-09-12）

## 范围与结果

按缺口盘点第 1 类及第 4 类补查，限定 **12 组操作链**。新增确认并修复 **2 类根因**；不重复计算已有文末代码块出口/整块选择修复，不将模型测试计为真实鼠标或原生验收。产品修改仅涉及 `MarkdownVisualEditor.tsx` 与 `markdownVisual/listKeys.ts`；保留所有并行改动，没有提交。

### 1. 删除选区后继续输入，撤销跨过删除后的状态

真实浏览器：唯一空代码块 → 点击“Select entire code block” → Backspace → 逐键 `a`、`b`、`c` → Cmd+Z，修复前直接恢复代码块，跳过删除后的空文档。

修复后为选区删除建立独立历史边界：第一次撤销只撤回 `abc`，第二次完整恢复围栏、语言、空行及结构选区。针对主编辑区的 Backspace/Delete 与 `beforeinput` 删除处理，不把普通选区输入替换拆成逐字历史；不会接管内嵌源码的按键。

三个以上维度：空/空格/多空行代码、图片及混合整篇清空；删除→逐字续写→两次撤销/重做；隔离保存内容与重新挂载核对；真实浏览器空代码与整篇清空双链。

### 2. 普通列表与引用的硬换行空占位不能正常退出

真实浏览器：`- <br>` → 点击空项 → Enter → 逐键 `aft`，修复前变成两条列表（第二项仍为 `aft`），没有退出到正文。此前任务列表的专用处理没有覆盖普通列表/引用。

修复为普通列表/引用中的纯硬换行占位补充退出行为；多次 Shift+Enter 产生的空内容同样可退出。保留真正零内容段落的原生处理与既有历史规则；空格、文字、图片等可见非文本内容不视为纯硬换行。Enter 与 Backspace 分开约束，避免将含行内图的任务提升到列表外。

三个以上维度：普通列表/引用与通过实际编辑生成的多硬换行；退出后逐字输入、逐层撤销；非空文字、空格、含图任务反例；真实浏览器列表/引用退出与撤销后继续输入。

## 合并前拦截与纠正

- 初步扩展接管了普通零内容空列表，改变了既有“连续两次 Backspace → 一次撤销”的历史。完整集成旧用例将其拦下；已限制普通列表/引用扩展仅处理含硬换行占位，**原断言未放宽**。旧混合列表删除/Enter/DOM 重解析 18 种结构组合再次通过。
- 并行鼠标 agent 交叉审查指出，Enter 若只看 `textContent`，会误处理 `image + hardbreak` 的任务。已限定 Enter 的所有子节点都必须为硬换行，并补实际编辑器 Schema 下从带文字行内图片去掉文字后生成的反例。该合并前回归不额外计入修复数量。
- 多行源码 `- <br>\n  <br>` 会进入现有保留块路径；没有把它强行当作普通列表测试。多硬换行改从列表清空后实际 Shift+Enter 生成。
- 工作区浏览器两次被并行源码热更新重新挂载，导致失焦；这些中断不计产品失败或通过。HTML 三层撤销改在主 agent 固定副本重新验证成功。
