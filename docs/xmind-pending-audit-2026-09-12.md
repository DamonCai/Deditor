## 已确认的实现缺口

1. **跨文档复制图片主题缺少资源迁移。** `XmindCanvas.tsx` 的剪贴板只序列化所选 Topic 数组，粘贴只提交 `paste` 主题命令；`writeDocument` 只替换目标归档的 `content.json`。源图片字节、资源重命名及 manifest 合并没有进入流程。按现有剪贴板序列化及生产 duplicate/paste/save 函数执行自建样例，目标文件没有 `resources/picture.svg` 时得到悬空图片引用；目标有同名但内容不同的图片时，得到指向错误图片的引用。
2. **复制多个主题时没有迁移它们之间的联系线。** 同一样例选中 A/B，源表包含 A→B 联系，剪贴板只包含两个主题，目标保存后联系数为零。还需要定义并验证复制集合内部端点映射、集合外端点保留策略、跨文档内部链接及一次撤销行为；不能把仅复制主题树的回归计作完整复制验收。

复现材料位于 `tests/artifacts/xmind-pending-audit-20260912/`：`source.xmind`、`missing-baseline.xmind` / `missing-saved.xmind`、`collision-baseline.xmind` / `collision-saved.xmind`、`results.json`。这是现有剪贴板数据流和生产文档函数的复现，尚未执行本次原生剪贴板操作，不伪称已经完成真实 UI 复测。两项均尚未修复。

## 仍可补齐的验收

- **形状及主题组合校准：** 当前矩阵的“更广主题组合继续核对”“紧凑形状折行、部分圆角尺寸未确认”仍未形成逐项闭环。现有实现的默认圆角为固定 8，紧凑形状使用内容测量后放大等几何规则；这些是需进一步对照的实现，不在没有原版新样例证据时直接判成 bug。可继续对照同一字号、显式宽度、图片/标签和浅深主题下的成对画面。
- **复杂连续编辑与资源压力：** 当前 `perf-xmind.ts` 测量 1,001 节点布局/归档及万控制点路径计算，不测真实画布连续输入、缩放、拖动、切表、50 步历史和关闭后资源释放。组件已有部分历史/释放回归，不能替代大图真实 UI 持续操作。可在独立浏览器及 macOS 测试包中分批执行，结束即关闭应用。
- **最终整合版本验证：** Review23 的固定快照验证仍有效，但共享编辑器此后持续变化。最终需冻结新的整合快照，验证 Markdown↔XMind 标签切换、快捷键/保存隔离及闭包历史，并将源码、完整回归、构建和实际测试二进制对应起来。不能将旧包结果自动归给最新工作区。
