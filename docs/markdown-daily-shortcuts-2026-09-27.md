## 实际浏览器工作流

使用当前真实React阅读组件、MarkdownToolbar、SearchPanel、CodeMirror，CUA驱动浏览器逐键操作；可见DOM、实际光标、源码面板逐步核对。隔离自建页面 `tests/markdown-shortcuts-deep-review.html`，不是用户文档；它不挂完整App窗口捕获层，该层另用原生包核查。

1. **写周报**：替换Start为`# Weekly`→Enter→`- first`→Enter→second→Tab→Enter→third→Shift+Tab→Enter两次退出列表→`> note`→Shift+Enter→continued。标题、两层列表、第三条回到同层、引用硬换行正确；一次撤销去掉continued，重做精确恢复，重新解析结构保持。
2. **格式开关**：真实Cmd+B/I先复现粗体吞掉全部后续文字；修复后同一步骤得到`**bold** normal *italic* tail`，strong/em分别独立。一次撤销只去tail，重做恢复；亮色/暗色720px、重新解析保持。
3. **查找后继续输入**：Cmd+F找嵌套项second→Enter→Esc，原生选区文本为second；直接输入revised只替换该项，层级不变。
4. **混合格式替换**：Cmd+Alt+F打开替换，cat→dog全部替换，实际DOM仍为strong/em/code/link，链接地址保留；Esc后Cmd+Z恢复cat，重做并重新解析后五种格式保持。截图`replace-formats.png`。
5. **普通代码块**：点开js块→Home→Tab→Shift+Tab→Cmd+Enter，源码缩进往返原样，焦点返回After段落；直接输入`NEXT `得到`NEXT After`，一次撤销恢复原文。
6. **快速插表与连续填表**：末段Enter→`/table`，候选仅表格→Enter插入两列两行；Tab依次移到下一格，Cmd+Enter到表格后，直接输入After table。初始A/B是真实表头文字，首格光标在A前，输入left结果leftA，未把它误记作自动替换占位符。
7. **末格增行与分步撤销**：末格输入last→Tab增第三行→输入added；一次撤销仅去added，第二次撤销去新增行，直接输入X得到原末格lastX，其他格和表后文字保持。

Home后扩选格式文字时会进入可编辑Markdown投影；复制会包含实际所选的源码符号（观察到尾部`**`）。这与渲染态选区不同，本轮没有将它误认为已经修复的复制bug；完整操作状态与范围见[剪贴板专项](markdown-daily-clipboard-search-2026-09-27.md)。
