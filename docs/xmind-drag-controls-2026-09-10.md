# 重复控件与批注拖拽修复（2026-09-10）

## 修改与横向检查

- XMind 格式面板：删除标题行关闭叉号，保留工具栏“格式”开关。大纲已有唯一开关，无需删除。
- 设置窗口：右上叉号与底部“完成”均执行 onClose，删除叉号，初始键盘焦点移到“完成”；Esc 和焦点恢复保留。
- 文件侧栏、Markdown/HTML 视图选择、JSON/SQL 工具栏、文件对比界面未发现本轮这种同区域重复开关。
- Markdown 预览搜索的叉号关闭搜索栏；标签叉号关闭文档；确认/输入弹窗的取消和确认承担不同动作。保留这些控件。
