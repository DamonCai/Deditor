# 顶栏隐藏标签下拉验证（2026-09-11）

用户要求：只把没有在顶栏显示的标签收进下拉，不重复列出已显示的标签。

实现：根据标签在可滚动顶栏中的实际边界计算列表，完全可见的标签不进入下拉，左右被裁切或完全移出视口的标签进入下拉；数字及搜索范围只包含这些标签。滚动、标签增删/排序、标签尺寸及窗口变化后重新计算。全部标签能放下时隐藏入口并关闭下拉，计算时计入入口消失后释放的32px，避免临界宽度下入口自身造成溢出。展开的下拉随顶栏尺寸变化更新位置。

仅使用本轮生成的六个标签，浏览器入口为 `tests/artifacts/tabbar-overflow/review.html`。没有读取真实用户文档或应用历史记录。

轮 1 — 用例：500px 顶栏，六个标签，展开下拉并搜索。
期望：已完整显示的标签不在下拉中，也不能通过搜索重新出现。
实测：顶栏完整显示 alpha、bravo、charlie；下拉仅列 delta、echo、foxtrot，数字3。搜索 alpha 显示没有匹配。
结果：通过，真实浏览器与组件回归。
