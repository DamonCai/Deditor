## 最终行为（名称与分隔线按用户后续反馈修订）

- 图表模式复用文档的「编辑 / 实时预览 / 阅读」及对应英文。默认阅读，单击选中，双击或预览区 Enter 进入实时预览。

- 分隔线扩大不可见点击范围，保留键盘焦点反馈；取消拖动、切换模式或销毁视图释放指针捕获，拖动不写 Markdown、不新增历史。
- 源码编辑即时写入原 Markdown，复用原有共享撤销；编辑器在模式间复用，保留选区。点击正文不收起所选模式，Esc 返回阅读。
- 实时预览在输入暂停 250ms 后刷新，保留上一张图至新结果完成；过期异步结果被取消或忽略。空源码显示输入提示，错误修正后可恢复渲染。
- 图表继续使用共用渲染链；本次仅针对实时预览宿主去除两侧框线，普通代码、公式和旧式图表沿用原交互。
