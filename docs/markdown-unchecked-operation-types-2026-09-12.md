# 阅读编辑操作检查缺口盘点（2026-09-12）

最初按用户要求先梳理；用户随后已授权三个 agent 并行检查与修复，执行结果见[本批整合记录](markdown-operation-gaps-results-2026-09-12.md)。盘点起点为 `bce1e9f`，当时工作区干净；以下来自已有记录的证据核对，没有重新运行产品测试。待检查项不是已确认的 bug。

## 这次文末问题带来的检查要求

需要从用户可见入口开始，验证“能找到入口 → 能选中或进入 → 能退出/删除 → 光标落在预期位置 → 能继续写 → 撤销后仍能继续操作”。通过内部接口设置选区或直接调用命令，只证明其中一部分。

[文末修复](markdown-document-end-fix-2026-09-12.md)已经覆盖代码末显示行退出、下方空白点击、整块鼠标选择与删除、选中块后 Enter，以及代码/公式/HTML/图片/表格/列表等文末矩阵。不能把这些重新列成“没有检查”。该修复的浏览器证据不等于新包原生保存、撤销、重开已经通过。

## 优先补齐的八类

“明确待补”表示记录直接注明缺少实测；“组合待补”表示已有局部用例，但本次未找到下面完整操作组合的验收记录，不表示每一个动作从未测试。

## 单列的验收缺口

- 真实中文输入法：候选出现、选词、取消、长停顿、组合期间滚动及撤销。模拟 composition 和直接输入中文已有覆盖，但不替代这项。
- Windows：原生快捷键、剪贴板、鼠标及窗口行为。macOS 结论不能迁移为已通过。
- 真实图床与网络：实际账号上传、失败和重试；与本机图片目录选择已通过的部分区分。
- 原生整合版本：文末修复、第三轮连续操作及最新目录 CSS 的证据分别保留；已有目录菜单原生闭环不能替代上述全部改动的整合验收。

## 后续执行方式

先做前三类。可分三个 agent 分别负责边界、整块/跨块选择、真实鼠标选区；主 agent 负责样例、证据与交叉复测。共享编辑器核心修改需指定唯一负责人，避免并行覆盖。该分工随后已按用户指令执行；主 agent 同时承担错误恢复与整合验证。

每个检查点记录：初始文档和位置、实际鼠标/逐键动作、预期、实测、是否复现、修复位置、撤销后续写、保存重开证据、平台和版本。修复数量按独立根因去重，检查点数与 bug 数分别统计。所有操作使用自建文档。

## English summary

This is an evidence audit, not a new test run or a list of confirmed defects. Eight coverage gaps are prioritized: document edges and sole-block documents; whole-block and mixed-block selection; real mouse selection; structural conversion and empty states; native clipboard and drag operations; UI entry points and focus handoff; layout changes during editing; interruption, recovery and sustained use. Existing document-end, outline/menu and sequence checks remain credited. Native IME, Windows, real image-host accounts and a unified native build require separate acceptance. Start with the first three categories and validate the next action after every operation, including undo.
