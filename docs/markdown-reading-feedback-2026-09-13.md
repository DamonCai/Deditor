# 阅读编辑五项反馈修复（2026-09-13）

范围：大屏/收起侧栏后的自适应、删除表格行、鼠标整行选择、选择卡顿、Mermaid/PlantUML 完整外框与去复制按钮。未提交推送，未改 XMind 专用功能。起始 Git 为 `58e917b`，工作区干净。

## 实施

- 阅读编辑与实时预览的在线文档面板使用可用内容区宽度，解除 860px 上限；保持共同字体、正文间距和边缘留白。最终规则只作用于在线显示宿主，导出保留原列宽。
- 表格右键增加中英双语“选中整行 / 删除行”，Shift+F10 也可打开，上下键切换、Enter 执行、Esc/Tab 返回正文。删除当前行或所选多行，表头删除后提升下一行，数据行全部删除后可以仅保留表头；删除后定位邻近行。
- 包装现有表格 node view，保留其行列控件及拖动能力；表格内容内的鼠标按下交由 ProseMirror 处理，去掉上游延迟设置段落 NodeSelection 的竞争。相同文档节点的装饰变化直接更新，避免重建整张表。
- 两种图表及别名的工具栏、源码/预览内容共用一个 1px、8px 圆角的完整边框；删除其复制按钮，保留“编辑 / 实时预览 / 阅读”、内部拖动分栏、固定模式切换高度。普通代码复制仍保留。
