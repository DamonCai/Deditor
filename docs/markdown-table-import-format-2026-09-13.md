# 表格导入格式兼容修复（2026-09-13，原生验收结束于 09-14）

用户提供 `bug_文件.md`，要求处理表格内未显示的列表和粗体。本次只修复表格解析，未写入用户原文件，未提交或推送。

## 原因与修复

- 导出内容中的序号使用 `1.\u00a0`，无序列表使用反斜杠转义标记加不换行空格（`\\-\u00a0`）。常规 Markdown 将它们当作文字。
- `**情报运营：**为正文` 一类中文标点结尾的粗体标签紧接正文，原解析器未识别闭合边界；多个标签之间的 `<br>` 还可能被归入错误配对的强调节点。
- `markdownTableSyntax.ts` 提供两端共用的兼容判定与虚拟源码边界映射。仅在表格内将列表标记后的 NBSP 归一化，兼容转义标记加 NBSP；普通转义标记、代码、正文中的 NBSP 保持原解释。
- Preview 在表格行内上下文识别纯文本中文标点标签；阅读编辑修复树内对应节点，递归识别真实 HTML 换行，再将列表解析结果映射回原文。
- 表格虚拟有序列表补齐 Milkdown 的序号元数据。测试曾发现未补元数据时，初始化的自动修复事务会重新序列化整张表格；修复后打开不改原文。
- 没有修改共享正文样式、HTML/XMind 组件或全局强调语法。
