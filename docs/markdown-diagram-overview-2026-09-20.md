# 图表全览、三模式与缩放（2026-09-20）

用户要求在 Mermaid / PlantUML 图框上增加全览，全览内保留编辑、实时预览和阅读，并支持缩放；测试完成后提交代码。本次提交同时包含此前已确认的图框自动高度调整。

## 行为与实现

- 图表工具栏增加“全览 / Full view”。原有图框仍随图自动增高；全览使用应用视口大小的原生 HTML dialog 顶层显示，避开文档滚动容器对 fixed 定位的限制。
- 复用原有工具栏、CodeMirror 和渲染节点，不复制编辑状态。编辑/实时预览/阅读、可拖分栏和删除动作继续使用原逻辑。
- 默认适应可用预览区域，支持放大、缩小、100% 原始尺寸、适应窗口，以及 Ctrl/Cmd+滚轮缩放；手动按钮范围 1%–400%，适应窗口可按超长图进一步缩小。
- SVG 缩放只改变临时显示尺寸，不写入 Markdown；退出时恢复 SVG 原有 style、正常图框高度、文档滚动位置，焦点回到全览入口。
- Esc 在右键菜单中先关闭菜单；否则退出全览。只读文档允许全览与缩放。删除图表、切换文件/离开阅读编辑和销毁节点都会清理顶层窗口。
- 源码右键菜单挂在全览内。其他应用弹窗打开前释放图表顶层，避免保存错误或确认窗口被遮挡、无法聚焦。

## 5 轮验证

仅使用自建内容，未读取用户文件、应用历史或状态。`tests/markdown-diagram-autosize-review.html` 可重复验证；Mermaid 使用真实渲染器，PlantUML 使用明确标示的离线自建 SVG，不能将后者计作远程服务验收。

轮 1 — 打开/关闭全览与三模式

- 期望：占满视口，编辑器实例与模式保留，Esc 返回当前图框。
- 实测：1280×720 中文亮色 Mermaid 全览边界为 `(0,0,1280,720)`，长图默认 35.2% 适配；三模式切换保持同一 CodeMirror。源码内 Esc 退出后保留实时预览模式，焦点返回全览入口，SVG 恢复原 style。
- 结果：通过。

轮 2 — 缩放、布局和窄窗

- 期望：缩放不改变内容，实时预览左右等高，分栏/窗口变化时自动适应。
- 实测：Mermaid 100% 再放大到 125% 后图高 2297.5px，图形可滚动查看；实时预览保持等高左右布局。720×540 英文暗色 PlantUML 全览完整覆盖视口，图高 467px、缩放 29.2%；分栏改为源码 80% 后图形仍完整位于右侧区域。单测覆盖 Ctrl+滚轮阻止页面缩放并改变图形比例、适应窗口和原始尺寸。
- 结果：通过。

轮 3 — 源码更新、保存和撤销

- 期望：全览内编辑立即更新图形，关闭不丢内容，保存与单次撤销仍精确。
- 实测：真实全览将自建长图替换为“全览编辑→完成”，实时预览显示新节点；Esc 返回后单次撤销恢复全部原文。自动化覆盖两类图表的编辑、保存正文精确一致、单次撤销及缩放样式恢复。
- 结果：通过。

轮 4 — 菜单/弹窗、删除、只读及生命周期

- 期望：全览不拦住必要弹窗，清理不会留下遮罩或隐藏焦点。
- 实测：Shift+F10 菜单显示在全览内，第一次 Esc 只关菜单，第二次退出全览；模拟应用保存失败弹窗前自动释放全览，焦点落在错误关闭按钮。真实全览删除 PlantUML 后全览和节点均消失，单次撤销恢复两图及精确原文。真实错误图在全览内改为合法源码后恢复图形，缩放控件重新启用，Tab 焦点留在全览内。自动化覆盖只读、空图禁用缩放、后台标签退出、销毁、快速重开后的迟到 close 事件及中英文文案。
- 结果：通过。

轮 5 — 相邻回归与构建

- 期望：既有图表三模式、历史全览、其他弹窗和阅读编辑不回退。
- 实测：24 图表组、11 历史差异组、107 阅读集成、完整 `test:regression`（146 通用 / 8 分隔线）及生产构建通过，`git diff --check` 通过。图框自动高度的五轮记录见 `markdown-diagram-autosize-2026-09-20.md`。
- 结果：通过。
