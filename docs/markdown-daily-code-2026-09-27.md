本专项使用实际 `MarkdownVisualEditor`、ProseMirror、CodeMirror、解析/序列化、历史和保存入口验证快捷键的结果。新增 `scripts/test-markdown-daily-code.mjs`，共 13 组，包含语言、退出方向、相邻块和源码类别的多维循环。

## 补齐的行为

普通代码与图表源码已有 Mod+Enter 返回正文。HTML/frontmatter 等保留源码块此前没有该绑定，实际 CodeMirror 按键会新增空行并继续留在源码中。本轮在 `rawView.ts` 接入已有 `exitBlockSource`，让 Mod+Enter 返回下方正文；需要时由现有退出逻辑插入正文段落，随后关闭块内源码并交回编辑焦点。属于快捷操作的一致性补齐，没有将该行为描述为数据丢失。

Escape 仍选中源码块；块首尾方向键仍只在空选区且到达精确边界时退出。没有修改普通代码/图表的换行、语言缩进或源码保留方式。
