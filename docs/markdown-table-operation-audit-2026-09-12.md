# 阅读编辑表格逐项验收（2026-09-12）

范围固定为操作清单 F01–F05；仅使用自建内容。本记录不代表阅读编辑全部操作或双平台验收完成，未提交推送。

## 本次复现与修复

1. **Shift Enter 在单元格内完全无效。** 上游默认禁止 table 内 hardbreak，而 DEditor 已有 `<br>` 保真方案。现只解除 table 的过滤，代码块仍保留原过滤。Enter 维持当前上游行为：退出表格到其后的段落；Shift Enter 表示单元格内换行。
2. **TSV 首尾空格保存重开后消失。** 首次粘贴的模型保留空白，但 Markdown 表格将其重新视为排版空白。现仅将真实单元格边界空格/制表符序列化为字符实体，重开保持内容；普通表格无需改写。
3. **单元格列表首项显示为 `| - alpha`，源码导航可能写进下一项/邻格。** mdast 的 cell 范围包含分隔符，旧处理直接解析完整范围。现使用实际行内内容范围，替换 `<br>` 时保存原文坐标映射，并让可视化解析和文档映射使用同一转换。列表内软换行也拆成精确的文本与换行范围，避免把 `pha` 位置定位到相邻 `two`。
4. **文档顶端表格列菜单被裁切。** 新表格专用菜单定位根据阅读滚动容器的空间上下翻转、左右夹紧。未修改全局溢出规则或正文尺寸。
5. **鼠标增加行/列后立即 Cmd Z 无效。** 上游增加按钮重建表格后没有恢复编辑器焦点。现捕获加号点击，并在操作后恢复编辑器焦点；删除控件沿用现有行为。
