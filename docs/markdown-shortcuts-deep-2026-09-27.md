# 阅读编辑快捷操作与整表缩进深测（2026-09-27）

## 需求与提交边界

按用户要求先将此前能力收尾完整提交为 `3521e33`（`fix: close out PlantUML, XMind and native spelling checks`），未推送。本轮快捷操作、表格缩进和测试属于该提交之后的新工作。

用户最终澄清为：**选中整个表格，按一次 Tab，整张表格缩进**。不要求连选上一行，也不强制把表格变成列表子块。完整输入前缀及按键清单见[快捷操作清单](markdown-reading-shortcuts-inventory-2026-09-27.md)，其中明确区别正文、单元格、列表和内嵌源码的同键行为，以及上游注册与实际应用覆盖。

## 实现

- 整表节点选择，或覆盖全部行列的单元格矩形选择：Tab 增加一级、Shift+Tab 减少一级，每级正文 2em，最低 0；保持选区，连续操作各自可撤销。可通过表格右键菜单「选中整表」建立选区。
- 单元格文字光标/局部矩形仍走前后单元格导航，末格 Tab 仍增行；全表选择不会增行。只读、组合输入、修饰键和跨块文字选择另有保护。
- 表格属性保存在首个表头的 `<!-- deditor:table-indent=N -->`，阅读和预览隐藏标记并保持相同偏移；全表富文本复制保留，局部矩形复制不继承。标准 Markdown 没有独立整表缩进语法，其他阅读器通常只呈现表格内容，不保证视觉缩进。

## 测试轮次与证据

1. **用户操作与浏览器对照**：原实现中右键选全表再 Tab 会增加空行；最终整表右移且仍为三行两列。连续 Tab/Shift+Tab、重新解析、亮暗与 720px 布局通过。正文 16px 时一级实际移动 32px，阅读表格和实际 `renderMarkdown` 预览左边界均为 64px（初始 32px）。
2. **列表专项**：[12组组件深测](markdown-list-shortcuts-deep-2026-09-27.md)覆盖6种前缀、Enter续写/空项退出、嵌套与后续段落、任务退格、表格前后列表、单元格列表、只读和组合保护。浏览器逐键 `- alpha`、Enter、`beta` 的同层文本左边界同为61px。用户所述偶发不齐尚未复现，不称已修复原始现象。
3. **表格专项**：[表格操作矩阵](markdown-table-shortcuts-deep-2026-09-27.md)覆盖全表和部分选择、单格表、方向/边界、Enter、删除、列表、撤销和保存重解析。预览/剪贴板8组覆盖双表、空表头、列表表头、垂直对齐、HTML粘回、普通copy与显式格式。
4. **原生独立包**：仅打开自建 `native-shortcuts.md`。右键 Select table → Tab → Tab → Shift+Tab → Cmd+S，得到一级缩进；原三行两列、左右对齐、列表和末段均保留。一次 Cmd+Z 保存精确仅将级别1改为2；一次重做保存、关闭、Cmd+Shift+T重开，文件与首次一级保存逐字节一致，表格位置保留。两次Shift+Tab在0级停止，单次撤销即回到1级（0级无额外历史），再次保存与一级快照精确一致。截图 `tests/artifacts/shortcuts-deep-2026-09-27/native-indent.png`。隔离配置 `bundle.fileAssociations: []`，未替换日常应用；自建文件保存关闭，测试应用已退出。

5. **深测发现并修复空格子写回错位**：清空第一正文格后逐键输入 `**bold**`，原代码DOM在原格但Markdown写到下一格（`boldtwo`）。空tableCell没有paragraph子节点，缺少零宽源码锚点而退回邻格。`document.ts`补空格子精确锚点，并把隐藏缩进/垂直对齐标记保留在正文之前。新增六条普通/粗体/代码输入路径及24格普通/元数据/列表内表格/CRLF组合，覆盖首中末表头和正文。浏览器同一路径粗体和末列行内代码写回/重解析通过。
6. **最终包追加验收**：重新生产构建及隔离macOS打包通过。原生点击第一格、Cmd+←/Cmd+Shift+→选择文字再退格清空，逐键输入格式符与字母，本机简体拼音将 `bold` 提交为“波兰队”；磁盘为第一正文格 `**波兰队**`，邻格two及其余正文不变。保存关闭重开后粗体和一级缩进保留，选全表Tab到二级、一次撤销保存恢复到之前逐字节快照。只确认实际提交后的文字/格式/位置，不扩展为候选窗或英文字母输入验收。截图 `native-final.png`。初次AX selectText与实际可编辑DOM选择不一致、删到了three尾部，已立即撤销并改用上述实际按键，不把这一步计为通过。最后文件保存关闭、隔离应用退出、浏览器和5185服务关闭。
