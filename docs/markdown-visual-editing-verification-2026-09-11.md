# Markdown 阅读编辑实施与验证

日期：2026-09-11。用户在架构讨论后明确要求执行。本次已接入可运行的核心版本，**不代表完整 Typora 体验、所有 Markdown/MDX 语法或双平台验收完成**。本记录只覆盖 Markdown 任务；同时进行的 XMind 修复由其独立记录管理。

## 使用入口与实现

打开 `.md` / `.markdown`，工具条有四种模式：**编辑、实时预览、阅读编辑、只读**。阅读编辑中直接修改文章；只读使用同一个呈现组件关闭输入。原有源码＋分栏预览保留，HTML 的三个模式仍独立使用原有 iframe。Markdown 模式单独持久化，旧阅读设置迁移为阅读编辑；不会改写 HTML 的预览开关。

- Milkdown Crepe / ProseMirror：正文、标题、文字标记、列表、任务框、表格、链接、图片、行内公式。
- CodeMirror：完整源码、代码块、公式/图表源码及保留语法块。Mermaid 本地渲染；PlantUML 沿用既有联网渲染路径。
- `MarkdownDocument`：原文与块范围为依据，文字编辑优先按原文 token 定位回写；结构变化只重序列化涉及的块。绑定实际编辑器初始文档，避免表格随机 ID 导致首次输入重写整篇。
- `MarkdownSession`：每标签共享源码补丁历史，源码、阅读编辑、工具条、代码块统一撤销/重做。连续相邻输入分组，切换模式打断分组；外部替换清理旧历史。历史仅在本次进程内保存，关闭标签时回收。
- 保存、另存、自动保存沿用现有 `fileio` 与 Rust IPC；视觉事务同步更新源码，并注册保存前 flush。格式化仍由既有显式命令/保存设置控制。
- 工具条、搜索、目录、Goto Symbol、Find in Files 跳转和状态栏接入当前可视编辑器。源码与阅读编辑保存光标映射；阅读/只读保持页面滚动。CSS 限在 Markdown 容器内，组件按需加载。
- 新文案同时提供中文与英文。依赖锁定并新增 `package-lock.json`，移除与可复现安装目标冲突的锁文件忽略规则。

## 保真与功能边界

无修改打开、模式切换、只读切换不应改写原文；测试覆盖 CRLF、额外空行、特殊列表编号、围栏写法、引用定义等。结构性操作（如增删表格行列、变更列表类型、增加标记）允许规范化**被修改的块**，不能据此承诺任意 Markdown 字节级往返。未涉及的块保留原文。

已识别的颜色/高亮 span、下划线、上/下标可作为可编辑标记；未识别 HTML、引用式链接及定义、frontmatter、脚注等进入保留源码块，可查看渲染并打开块源码。渲染 HTML 经净化，原始源码仍保留。`.mdx` 整篇按保留块处理，提供源码入口，**不会执行 JSX，也未实现 JSX 的所见即所得编辑**。

图片保留标准 alt 和路径，上游把 alt 用作比例的行为已覆盖。暂不提供图片拖动缩放（标准 Markdown 没有对应的持久化比例，已隐藏该操作）。表格支持直接编辑、Tab/Shift+Tab 导航、末格 Tab 增行、上游行列/对齐控件，并适配既有 `<br>` 表格内列表。浏览器已实际验证单元格输入、末格增行和保存重载；所有行列控件的逐项原生验收仍待补齐。

## 自动化结果

以下为首次实施阶段记录。后续提交前独立快照已完成 12 项集成、117 项组件及完整 XMind/导出/高亮/图标/性能/Rust 测试，见 [提交前验证记录](markdown-release-verification-2026-09-11.md)。两阶段工作区范围不同，以该记录为最终提交证据。

首次阶段命令及覆盖：

- `npm run test:markdown-visual`：**24 项通过**，其中一项遍历 14 组保真样例。
- `npm run test:markdown-visual:integration`：**10 项通过**；使用真实组件、store、历史与 fileio，只有 IPC、系统对话框和 opener 被隔离替换，写入内容可断言。不是原生磁盘保存证据。
- `npm run test:regression`：**118 项通过，0 失败**，包含原有 HTML、编辑器、保存和 XMind 回归。一次中间执行曾出现 XMind mixed-style 断言失败；独立 XMind 任务更新后最终完整执行通过，本任务未修改 XMind 实现来规避断言。
- TypeScript 检查及生产构建通过。可视编辑器为独立懒加载块，约 950 KB（gzip 约 296 KB）；既有大块告警仍存在，未把构建通过当作启动或内存性能验收。

### 轮 1 — 基础正文与保存

期望：打开/切换不产生修改；文章输入同步到源码；保存拿到最新内容。

实测：14 组样例的打开/切换保持原文；真实组件 DOM 输入同步到 store 和保存参数；浏览器标题编辑仅改目标文字。初始表格 ID 不一致导致全篇规范化的问题已修复后复验。

结果：通过所列自动化和浏览器用例。

### 轮 2 — 格式与语法边界

期望：中文、CRLF、列表编号、围栏、引用、HTML 扩展和表格扩展保持语义及未改范围。

实测：24 项文档测试覆盖相关样例；浏览器任务勾选仅替换 `[ ]`，颜色 span 文本修改保留周围原文，图片插入后 alt 与本地路径正确。表格空格、转义文字、空单元格、`<br>`、表格内列表分别覆盖。图片说明被上游改成 `1.00` 的问题已修复并复验。

结果：通过所列用例；不扩大为所有语法组合均通过。

### 轮 3 — 模式、历史和文件类型组合

期望：源码与阅读编辑共享有序历史，多标签及 HTML/XMind 不互相影响。

实测：浏览器执行 Markdown 阅读修改→源码修改→两次撤销，精确恢复初始文本；另一 Markdown 标签的修改在 HTML 修改/撤销后保留。HTML iframe 更新正常，XMind 专用画布修改主题后撤销恢复。组件测试覆盖另存、保存全部、卸载/重挂载历史，以及列表切换和撤销。

结果：通过浏览器组合与隔离保存测试；原生多文件关闭/重启/重开链路尚未验收。

### 轮 4 — 异常与异步内容

期望：保存失败不丢草稿；未知语法可恢复；图表异步返回不覆盖新文档。

实测：模拟写入失败时保存 Promise 拒绝，dirty 文本仍保留；外部文本替换与历史失效有测试。浏览器 MDX 源码编辑、保存快照保留 import 与 JSX；Mermaid、LaTeX 和 PlantUML 均显示渲染结果，图表源码修改同步回写。异步渲染有取消和版本检查。

结果：通过所列失败路径和联网图表实例；网络超时、原生权限拒绝、真正的输入法组合与并发外部变更仍需原生环境进一步验证。

### 轮 5 — 最近修复、布局和性能观察

期望：键盘和只读不绕过文档层，新增交互不会重现已发现问题；窄窗口可用。

实测：表格 Tab 原先插入空格，现已接管为导航/增行，自动化与浏览器复验通过。跨粗体搜索得到 `1 / 1`，目录跳转有效；任务框可用空格操作。只读关闭主编辑区和内部 CodeMirror 输入，并测试空代码块 ArrowDown 不新增段落。浏览器 720×900 深色截图中工具条换行、表格及图片正常，页面宽度与滚动宽度均为 720，无整页横向溢出；也已查看亮色界面。

2000 段自建文档的文档层测试多次运行中，最近一次为加载约 151 ms、一次目标编辑约 1.8 ms（此前多次为 122–209 ms / 1.9–7.3 ms）。这是解析/回写观察值，**不是原生完整页面输入延迟、长期内存或模式切换基准**。

结果：所列回归通过；性能与双平台大规模交互验收仍未完成。
