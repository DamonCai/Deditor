# 阅读编辑图块滚动与整表拖动（2026-10-14）

修复图块排序后的视口跳动，并为整张表格增加顶部拖动手柄。整表复用图块的落点线、边缘滚动、取消与同父容器排序规则，聚焦手柄后支持 Alt+↑/↓，一次移动对应一次撤销。表格手柄位于 contentDOM 外，不写入 Markdown，不替换原有行列控件。

## 滚动原因与修复

原移动事务使用 `scrollIntoView()`，会将整个 NodeSelection 拉入视口；长图超过一屏时，这不等于保留落点附近的阅读位置。移动现在保持松开时的纵向与横向滚动位置，整块选中不触发打字机居中。

只取消强制滚动还不够。真实浏览器的 1589px 长图样例中，重建 NodeView 时预览暂时为空，页面高度收缩，随后 SVG 出现又触发滚动锚定。第一版修复实测 scrollTop 为 2864 → 2557（即时）→ 2619（下一帧）→ 4107（渲染完成）。最终版在移动事务期间传递原图高度，新预览完成或报错后解除占位；同一样例四次采样均为 2864。占位仅在视图中存在，不进入源码，也不依赖固定延时或持续强制滚动。
