# Markdown 行尾 HTML 光标修复（2026-09-12）

用户反馈：`* [引用文字][guide] 和 <kbd>Ctrl</kbd>` 在阅读编辑中无法把光标放到最右侧。

## 复现与修复

使用自建长文 `tests/fixtures/markdown-interaction.ts`，浏览器实测点击 Ctrl 键帽右边的空白，DOM 光标仍在 `kbd` 文本末尾，输入 Z 得到 `<kbd>CtrlZ</kbd>`。行尾没有区分 HTML 格式内外的光标状态。

`src/lib/markdownVisual/cursor.ts` 现在允许向右退出行尾 HTML 格式、向左返回内部；点击键帽右边空白直接选择外侧。外侧状态使用零宽视图装饰给浏览器原生光标提供正确边缘。装饰不属于文档模型，不写入 Markdown；仅处理当前文本块，继续使用原生光标，组词期间不接管方向键或 DOM 选区。

## 验证

- 新增核心用例在修复前失败（向右键没有处理行尾 HTML），修复后通过。覆盖段落、列表、引用、表格中的键帽及颜色标签、内外点击、向左返回、组词事件避让和原文不变。
- 浏览器长文实测：光标显示在键帽右边框外；外侧输入产生 `<kbd>Ctrl</kbd>Z`，向左返回后输入产生 `<kbd>CtrlY</kbd>`；连续向右进入下一条列表；鼠标外侧输入中文同样落在标签外。键盘撤销恢复原文。
- 新增集成用例覆盖外侧输入、保存和撤销，验证零宽装饰不会泄漏进保存文本。
- 核心测试 49 项、集成测试 92 项、组件回归 144 项及生产构建通过。复杂文档阅读编辑与实时预览 465 项呈现对照无差异。

验证日志位于被忽略的 `tests/artifacts/caret-*.log`。本次没有运行新版 macOS 原生包或 Windows 验证，没有新增真实输入法验收结论。工作区另有独立 Markdown/XMind 改动，本修复不提交推送。
