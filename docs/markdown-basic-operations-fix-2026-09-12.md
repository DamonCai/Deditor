# Markdown 基本操作横向检查（2026-09-12）

## 范围与并行边界

用户要求先阅读“bug修复”会话，再检查 Markdown 的日常操作。本次锁定正文输入、删除快捷键、回车、任务列表、选区替换/加粗、普通与格式粘贴、表格换格、保存和撤销。全部使用自建文档。

“bug修复”会话同时在修正 `document.ts`、`inlineSource.ts` 及内容同步的光标恢复。没有覆盖它的改动，也没有把它尚未闭环的回跳问题计作本次修复完成。当前整合工作区继续变化，本记录只描述本次固定快照的证据。

## 已复现并修复

1. **括号配对吞掉删除快捷键。** 在 `alpha beta()` 的括号之间按 Command+Backspace，旧输入辅助直接删除整对括号。现在带 Command、Control、Option 或 Shift 的按键交还原有快捷键/平台处理；普通 Backspace 仍可成对删除。自动表情候选也不再吞掉带修饰键的 Enter/方向键。
2. **完成任务回车继承完成状态。** `- [x] completed` 末尾或中间按 Enter，新任务原先继承勾选。现在仍调用正常列表拆分命令，仅把新项目设为未完成；覆盖嵌套任务，旧任务与其他项目状态保留。空任务退出列表、Shift+Enter 和普通有序/无序列表沿用原行为。
3. **普通粘贴丢失空格。** 在 `alpha beta` 后粘贴 ` first`，旧路径先当 Markdown 解析再经过 DOM 解析，实际变成 `alpha betafirst`。现在无格式普通文本采用 ProseMirror 已处理的文本片段，保留首尾空格、重复空格和多行文本。Markdown 标题/列表/强调、HTML、VS Code 元数据、表格矩形粘贴及代码位置继续使用各自原路径。普通多行粘贴按文本片段形成段落。

产品改动位于 `inputAssist.ts`、新增 `plainTextPaste.ts` 和 `MarkdownVisualEditor.tsx` 的粘贴接入；没有新增设置或改正文 CSS。
