# Markdown 三种颜色设置（2026-09-30）

用户确认背景色范围：普通内容作用于段落，表格内作用于单元格。完成后提交并推送。

## 行为

- 工具栏依次提供文字颜色、文本突出显示颜色、背景色，使用 A、荧光笔、油漆桶图标；中英文名称明确区分。
- 前两种仍是行内格式；背景色覆盖所在段落／标题或整个单元格，支持跨段选择和矩形单元格多选。列表、任务列表、引用与提示块中的段落同样支持。
- 背景色面板提供“无背景色”，清除时保留文字颜色、高亮与其他格式。沿用主题色、标准色、自定义 HEX、原生取色器、键盘导航及目标选区保护。
- 未显式设置文字颜色的内容，根据底色使用黑／白文字，使亮暗主题均可阅读；显式行内字色优先。
- 空选区连续设置颜色后继续输入，保留待输入的文字颜色和高亮。修复颜色面板恢复选区时丢失 stored marks 的已有问题；背景色事务也保留它们。

## 持久化与范围

背景色使用段落／单元格开头的空行内标记 `<span data-deditor-background="#RRGGBB"></span>` 保存。空 span 不会把整段变成 HTML 块；读取时消耗元数据，正文保持可编辑。源码模式可见该扩展标记，阅读、实时预览及 HTML 输出将其转换为块级背景。其他 Markdown 阅读器没有此扩展时仍显示正文，但未必显示段落底色。

段落、标题、表格 schema、源位置映射、预览及富文本 HTML 均接入同一状态；与表格缩进、垂直对齐、任务缩进共存。提示块首段有底色时独立保存提示标识，避免 HTML 相邻时换行被序列化为空格。源码命令按需加载解析器，并在加载后复核原编辑目标。
