# 近期文件面板（2026-09-22）

根据用户“像 IDEA 一样查看近期打开的文件，快捷键 Command+E”的要求实施。

## 行为

- 文件菜单新增“近期文件 / Recent Files”，Cmd+E（macOS）及 Ctrl+E（Windows/Linux）；命令面板也有入口。现有设置可禁用该快捷键，菜单点击仍可使用。
- 按最近访问顺序显示最多 100 个具名文件，包含已经关闭的文件；切换标签、保存为新路径、重新聚焦窗口会更新顺序。未命名文档和临时差异标签不记录。
- 文件名和完整路径均可过滤，支持中文、Windows 路径及空格分词。↑/↓ 选择、Enter 打开、Esc 关闭；当前文件排第一时默认选中上一文件，方便快速切回。
- 已打开文件复用原标签。文件不存在或无法读取时在面板显示错误，可继续筛选并打开其他文件；重复 Enter 不会重复发起打开。
- 近期面板与文件搜索、命令面板、符号搜索、全局搜索、设置双向互斥，沿用模态焦点管理和现有快速导航尺寸/主题。
- 历史只保存文件路径。使用应用数据目录独立 `recent-files.json`，Rust 互斥锁保护读取—修改—原子替换；全部编辑器窗口共享并接收更新，辅助窗口关闭不会清除历史。启动恢复慢读不会覆盖其他窗口较新的广播。
- 从启用该功能后的访问开始记录；没有扫描用户磁盘，也没有导入系统原生近期文档数据库。

## 五轮自动化

轮 1 — 打开、切换、关闭及重新聚焦窗口。
- 期望：最近访问在前、去重，已关闭路径保留，临时差异标签不入历史。
- 实测：真实 store 订阅和自建 IPC 桩精确核对顺序；窗口焦点可更新共享历史。
- 结果：通过。

轮 2 — 历史读取与持久化边界。
- 期望：跨窗口更新优先于旧异步读取，中文/Windows路径可搜索，容量有界，保存后可重读。
- 实测：模拟慢读取与窗口广播交错，旧结果未覆盖新列表。Rust 自建临时目录写入 105 条、重访去重、容量 100、原子临时文件清理和重读通过；非法路径/损坏 JSON 报错且不覆盖原文件。
- 结果：通过。

轮 3 — 面板与快捷键交互。
- 期望：默认上一文件、箭头/Enter 打开、焦点恢复、快捷键开关及窗口互斥有效。
- 实测：StrictMode 下打开文件和退出、焦点返回、Cmd/Ctrl快捷键及禁用、近期与其他五类窗口双向切换断言通过。
- 结果：通过。

轮 4 — 错误与快速输入。
- 期望：缺失文件可恢复、快速重复打开不重复执行、空列表键盘操作安全。
- 实测：缺失文件错误后继续筛选打开成功；两次 Enter 仅调用一次打开；空列表箭头/Enter/Esc通过。
- 结果：通过。

专项入口：`node scripts/test-recent-files.mjs`；Rust `cargo test --manifest-path src-tauri/Cargo.toml recent_files::tests`。本 agent 的 TypeScript 检查、147 通用与 8 分隔线回归通过。最终生产构建、真实浏览器亮暗中英文/宽窄验收已通过，见 [整合记录](diagram-recent-files-2026-09-22.md)；上述 DOM 测试不能替代原生验收。

轮 5 — 成功切换后的编辑焦点。
- 原生初验发现：Enter 切回已打开 Markdown 后，模态清理恢复旧标签输入区，目标编辑器未持有焦点。
- 修复：成功选择后，在面板释放焦点捕获及恢复调用者之后，把焦点交给目标编辑器；阅读编辑优先恢复其原有选区。首次加载采用编辑器注册订阅等待，不循环逐帧轮询。Esc 仍只恢复调用者。
- 实测：成功选择后目标输入区获得焦点、延迟阅读编辑器注册后恢复选区、重新打开设置/切换文件/关闭阶段取消请求、图片不等待文本编辑器、Esc 保留调用者均通过。PDF、XMind 等二进制视图及 CSV/HTML 纯阅读模式同样直接结束文本焦点请求。
- 结果：五轮专项及 TypeScript 检查通过；最终原生包已验证冷打开/已有标签目标焦点，无需点击正文直接粘贴并保存、撤销恢复原文通过，重启近期记录保留；见 [最终核验](diagram-recent-files-2026-09-22.md)。
