# Markdown 标题提示按光标显示

日期：2026-09-11。用户要求参照钉钉文档，仅在光标移入标题时显示 H1–H6。

## 实现

- 仅在阅读编辑器获得焦点、文本光标折叠且位于标题中时，显示该标题的级别。
- 光标进入正文、选中文字、编辑器失焦、只读或实时预览时隐藏。
- 使用 ProseMirror 节点装饰和原有侧边空位；不修改标题节点属性、Markdown 原文或撤销历史，也不改变正文尺寸。保留绝对标题级别输入规则与已有中文组词滚动保护。
