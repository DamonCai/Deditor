# Mermaid / PlantUML 图框自动高度（2026-09-20）

用户明确选择“框随图自动增高，取消框内上下滚动”。本次以该要求取代此前首次切换模式固定图框高度的行为。

## 修改

- 阅读和块内实时预览移除 `60vh` 高度上限与首次模式切换高度锁定，图形完整放在文档流中，随正文一起滚动；短图自动收紧边框。
- 实时预览由图形决定行高，源码区域等高并单独处理源码滚动，不因代码行数把短图撑出大块空白；源码编辑模式仍有合理的编辑区高度上限。
- 图形容器取消内部纵向滚动及重复外边距。PlantUML 生成的 SVG 即使带内联固定高度，也在窄窗按 viewBox 比例显示，不拉伸。
- 无 Markdown 格式或保存内容变化，普通代码块及其他图表类型的行为不变。

## 验证

仅用自建文档。浏览器入口 `tests/markdown-diagram-autosize-review.html`，支持 `dark` / `en`；Mermaid 使用真实渲染器，PlantUML 使用明确标示的离线自建 SVG（含内联宽高），验证容器布局，不将其记作远程 PlantUML 服务验收。

轮 1 — 长图完整展开（1280×720 中文亮色）

- 期望：两类长图完整位于框内，图形预览不再单独纵向滚动。
- 实测：修复前两者都被限制为 432px，内容分别需 1862px / 1624px；修复后框高为 1862px / 1624px，与实际图形及内边距一致，`scrollHeight - clientHeight = 0`，SVG 上下边界都在框内。
- 结果：通过。

轮 2 — 短图、横向宽图与窄窗（720×600 英文暗色）

- 期望：短图缩短边框，宽图保持比例，无横向或纵向截断。
- 实测：短图框高分别为 94px / 184px；宽图 SVG 均适配到 575px 宽。Mermaid viewBox 宽高比 28.820、实际 28.840（像素取整），PlantUML viewBox 比 15、实际 15.002；图形区域无纵向溢出。
- 结果：通过。

轮 3 — 模式切换、分栏调整与源码修改/撤销

- 期望：模式切换不锁定旧高度，拖分栏时按新宽度更新高度，改源码后同步伸缩且单次撤销恢复原文。
- 实测：长图实时预览左右等高；720px PlantUML 实时预览从 50% 分栏改到源码 80%，框高从 1246px 变成 449px，图形无纵向溢出；编辑再切阅读恢复到自然 1624px。Mermaid 直接把短图源码改成四节点竖图，实时预览高 406px，撤销再切阅读回到 94px，原文精确一致。
- 结果：通过。

轮 4 — 空图、错误与恢复

- 期望：空图正常提示，错误可见，纠正后恢复自适应。
- 实测：空图提示正常；Mermaid 无效源码及模拟 PlantUML HTTP 503 错误可见；随后切回合法短图，两类错误清空，恢复 94px / 184px，原文一致。
- 结果：通过。

轮 5 — 相邻回归与生产构建

- 期望：图表三模式、别名、删除/撤销、只读、普通代码和数学块不受影响；通用回归与生产构建通过。
- 实测：18 图表模式组、`test:regression` 146 通用 / 8 分隔线组及 `npm run build` 全部通过；`git diff --check` 通过。
- 结果：通过。
