## 范围

## 修改

- 从真实 Preview 抽出共享 `MarkdownOutline`：相同的右侧目录短线、悬浮面板、固定／取消固定、层级缩进、空态、Esc 和键盘入口。阅读编辑不再保留另一套过滤／折叠侧栏或目录开关按钮。
- 两种宿主共用预览原有的章节高亮规则，包含靠近文末时渐进扩大判定范围，以及同一滚动位置上多个尾部标题的点击保持。标题编辑／源码同步后目录内容与位置更新；未变条目不触发额外目录状态更新，行内源码展开不把格式标记带进目录标题。
- 实测发现 Preview 中文目录点击失败：目录传入编码后的 heading id，查找却只解码 DOM id。已对两侧统一匹配，重复中文标题可跳到对应章节。
- 原生“编辑”菜单新增“查找…”／“替换…”（英文 Find…／Replace…），快捷键为 Cmd/Ctrl+F、Cmd/Ctrl+Alt+F。阅读编辑和源码编辑均可响应；替换命令聚焦替换框，关闭搜索返回文档。菜单事件检查当前活动文档，避免隐含编辑器抢走请求。
- macOS 原有系统注入项清理需保留 Tauri 自定义菜单分发 selector，否则新增菜单条目会被清理掉；仍清理其他系统注入项。

## macOS 原生闭环

隔离应用标识 `com.deditor.outlinereview20260912`，仅编辑 `/tmp/deditor-outline-native/outline.md` 自建样例。

1. 实际打开原生“编辑”菜单，确认“查找…”和“替换…”均存在，系统额外注入菜单未混入。
2. 点击“查找…”并输入 `target`，显示两项匹配。点击“替换…”后直接键入 `changed`，内容进入替换框。
3. 初次保存过程出现窗口状态变化，磁盘核对未发生替换，未计为通过；重读确认仍是同一自建文档，再次操作。
4. Cmd+Alt+F 打开替换框，全部替换、Esc、Cmd+S 后，磁盘内容精确等于原文把两处 `target` 改为 `changed`。
5. Cmd+Z 一次、Cmd+S 后，与基准文件逐字节一致。
6. 切到源码编辑，Cmd+Alt+F 打开 CodeMirror 搜索面板，直接输入 `probe` 落在替换框，正文不变。
7. 返回阅读，真实点击目录短线展开、固定目录、选择最后一个同名标题，光标到第 9 行且目录末项高亮。
8. 保存、关闭测试文档，从文件树重新打开：两处 `target` 原文和固定目录保留。测试文档再关闭，隔离应用退出。
