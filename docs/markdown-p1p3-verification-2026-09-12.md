# Markdown P1–P3 实施与验证（2026-09-12）

## 范围与结论

用户要求执行完整优先级、使用复杂 Markdown、保持阅读编辑与真实预览的样式一致，并更新 README、上下文、提交推送。本次继续完成可独立推进的 P1–P3 开发；P0 真实拼音和 Windows 验收仍未完成，不能将本文写成“全部平台、全部交互已通过”。

### P1：行内编辑、表格和列表

- 光标进入粗体、斜体、删除线、行内代码、链接时展开原始语法；退出、失焦或 Esc 恢复排版。展开是临时文档投影，不生成源修改或撤销步骤。
- 原文范围映射覆盖临时行内节点；直接改标记、保留未闭合标记、多行粘贴、跨块选区、只读切换、工具条格式化和撤销有回归。剪贴板 HTML 不可重新导入私有投影节点。
- 表格矩形粘贴复用 ProseMirror tables 的结构操作，支持扩展行列、引号包裹的制表符/换行及列对齐。超过限制的输入交回普通文本粘贴，不吞掉内容。
- 现有表格增删行列、Tab/Shift+Tab 与列表 Tab 缩进、Shift+Tab 提升、连续 Enter 退出继续使用成熟键盘逻辑。

### P2：扩展语法和图片

- 保留源码块中的嵌套 Mermaid/PlantUML 也执行图表渲染；打开源码、重绘与销毁时取消旧异步请求。
- 脚注、文内 `[TOC]` / `[[toc]]`、YAML 文档头、五类提示块接入共享 Markdown 渲染。脚注使用整篇文档上下文编号；TOC 随标题更新。
- 统一阅读编辑与 markdown-it 的标题锚点，包括重复标题、嵌套标题与行内强调。锚点使用装饰，不再通过源文档事务写入生成 ID。
- 图片宽度可设置、清空、保存和重开；显式宽度写成 `<img width="…">`，保留 alt/title。只将属性受支持的独立图片 HTML 转为图片控件，其他 HTML 继续保留源码。
- 图片目录默认 `assets`，可配置相对多级目录；Rust 验证相对目录及文件名，源码粘贴与阅读编辑上传共用。
- 另存时维护相对图片目标；应用内移动/重命名更新已打开 Markdown 中的图片及图片引用定义，不改代码示例和普通链接。修改进入历史、保持可撤销，后续保存写入；图片文件名中的 `%20` 按实际空格匹配移动目标。未打开文档与应用外移动不在自动维护范围。
- 修复同一批状态更新改变路径和内容时，退出的旧阅读视图可能覆盖新内容的问题。

### P3：写作与导出

- 默认、衬线、紧凑主题在阅读编辑与预览同时生效。
- 段落聚焦只影响正在编辑的阅读视图；临时行内源码仍归属其正文块。
- 打字机模式必须显式启用，默认关闭；组词、确认保护期和失焦时不自动居中，不因手动滚动自动重定位。
- HTML/PDF 的默认、报告、紧凑模板及文章主题被导出快照捕获；PDF 固定使用浅色打印背景，内容高度与溢出不受预览滚动容器限制。
- 写作设置持久化，老状态缺字段时恢复安全默认值。中英文文案在独立 Markdown 文案模块对称维护。
