# 单项闭环：含普通链接的正文源码同步

## 锁定范围

本轮只处理普通行内链接所在段落的一次单行源码修改导致整篇解析的问题。产品修改限定在 `markdownVisual/document.ts` 的 reset 快速路径；不改输入法、搜索、配对、词典、展示样式、HTML/XMind 或导入导出。

验收条件：修复前复现整篇解析；修复后只解析当前块；结果与完整解析相同，未变节点继续复用；引用式链接、脚注、HTML、结构变化仍安全回退；复杂长文真实浏览器编辑/切换/保存快照/撤销/重做通过；两种模式呈现一致；运行核心和阅读集成回归及生产构建。

## 验证与结果

已闭环。产品只改 `markdownVisual/document.ts`：不再把所有含 `[` 的段落都当作依赖全篇上下文。先检查块语法树，普通行内链接可局部解析；引用式链接、图片引用、脚注、HTML 或文本中尚未解析的方括号仍回退完整解析。原有换行、围栏和容器的保守边界不变。

### 修复前复现

- 新增回归在修复前失败：仅修改一个含链接段落，却将 12,073 字符全部传给解析器，耗时 24.55 ms。
- 真实浏览器生产验证页：6,303 行 / 152,241 字符 / 500 个附加表格，在第 9 行含普通链接的段落开头输入 `LINKPERF`，没有修改 YAML 或其他行。
- 三次返回阅读加下一帧耗时：808.9、797.1、715.3 ms；reset：290.6、289.1、255.9 ms；均调用全文 index。

### 修复后复测

- 同一核心用例只解析当前段落的 59 字符，约 1.08 ms；结果与完整解析相同，未变节点保留身份，CRLF 和后续源范围精确。
- 同一浏览器、同一长文、同一位置与输入，三次返回阅读：454.3、480.9、488.1 ms；reset：3.5、3.3、4.0 ms，不再调用全文 index。
- 返回阅读中位数 797.1 → 480.9 ms，reset 中位数 289.1 → 3.5 ms。三次样本用于本轮前后对照，不是所有设备或真实中文输入法的延迟承诺；首次打开、引用上下文和结构变化仍有完整解析开销。
- 三次均确认修改只发生在第 9 行、保存快照与修改版完全一致、撤销与原始 152,241 字符完全一致；另外验证重做恢复修改版，再撤销恢复原文。
- 复杂 Typora 扩展样例两侧 540 项呈现检查 `differences: []`，浏览器没有错误。测试标签已关闭，两个本轮测试服务已停止；未启动原生应用。

### 回归与交付边界

完整自动化通过：58 文档核心、102 阅读集成、144 通用组件、119 XMind、13 导出，以及语法和文件图标回归；生产构建通过。随后只新增标题和表格含链接的完整解析对照断言，58 核心再次通过。覆盖链接标题/地址/文本变化、中文和组合内容、链接去除、引用式链接、图片引用、脚注增删、HTML、转义方括号及后续源范围编辑。

不改变显示 CSS、字体、输入法、配对或词典；未提交推送。此次不重做原生输入法或 Windows 验收，也不把本轮性能闭环说成整个 Typora 清单完成。并行工作区原有修改保持原样。

证据位于 `tests/artifacts/markdown-inline-link-performance-2026-09-12/`，包含修复前失败日志、修复后回归/构建日志、浏览器数据、受测源文件与 SHA-256 清单。证据目录被 Git 忽略，迁移需单独复制。
