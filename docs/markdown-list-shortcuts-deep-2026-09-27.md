# 阅读编辑列表快捷操作深测（2026-09-27）

本轮从 `3521e33` 后工作区检查用户所述「`-` 加空格变黑点，后续文字有时需要 Tab 才能与上一行同层」相关操作。**在本组实际组件测试中没有复现需要额外 Tab 才能形成同级列表项的问题，没有据此修改列表产品代码。** 主端的真实浏览器/原生验收另行记录；整张表格单独 Tab 缩进的新功能由表格组实施，不把此前讨论的“附属前一个列表”当成最终需求。

## 操作清单与当前行为

| 动作 | 核对结果 |
| --- | --- |
| 在空段逐字输入 `- `、`* `、`+ `、`1. `、`3. `、`- [ ] ` 后继续输入 | 自动进入对应列表，正文没有多余前导空格，光标继续位于新列表项 |
| 列表行末 Enter 后输入下一项 | 新项与前项处于同一列表深度，不需先按 Tab |
| 列表内 Shift+Enter 后输入 | 留在同一列表项的软换行；再按普通 Enter 才建立下一列表项 |
| 新建空列表项再按 Enter | 退出到根级段落；此时重新逐字输入 `- ` 可建立根级列表，不残留旧层级 |
| 非首项 Tab / Shift+Tab | 列表项和所含子树整体降低/提升一层；保留任务状态和邻接表格 |
| 首个普通无序/有序项 Tab | 没有可嵌套的前项，安全保持原样，不插入字面空格；Shift+Tab 去掉列表标记，成为根级正文 |
| 正向/反向选中连续两项后 Tab | 两项一起降低一层，保留选区方向，不移动后一项或后面的表格 |
| 列表中的续段或标题 Shift+Tab | 只提升当前续段/标题；前面列表正文和后面嵌套表格保持原来的归属 |
| 普通嵌套列表首项行首 Backspace | 移除该项标记，成为父列表项的续段；这是现有上游行为，不等同于 Shift+Tab |
| 嵌套任务行首 Backspace | 按现有任务规则提升一层，保留任务状态和其他项；未强行统一普通列表与任务差异 |
| 表格单元格内输入列表前缀 | 保留产品已有单元格内列表能力；保存源码重新解析后仍为同一列表结构；Tab/Shift+Tab 继续导航单元格 |
| 表格之后的列表退格、Enter、重新输入 `- ` | 列表操作不破坏前面的表格；新的列表仍可直接输入 |
| 有序列表内混合普通项、已完成/未完成任务，Tab/Enter/Shift+Tab | 保留已完成项状态，新拆出的任务为未完成，父子层级正确 |
| 只读或真实组件 compositionstart 后按列表快捷键 | 不执行列表结构修改；模拟组合事件不等同于真实系统中文输入验收 |

对于“下一行对不齐”，本轮能明确区分普通 Enter 建立同级项、Shift+Enter 留在原项、空项 Enter 退出、Tab 降层、Shift+Tab 提升这几种不同动作。若真实文档仍出现意外对齐，需要保留触发时的源码/选区/按键序列继续定位；不能用本轮有限样例宣称任意文档均无问题。

## 验证方法与结果

新增 `scripts/test-markdown-list-shortcuts-deep.mjs`，最终 **12 组通过**。它挂载实际 React `MarkdownVisualEditor` 与 Milkdown/ProseMirror：

- Enter、Tab、Shift+Tab、Backspace 通过编辑器 DOM `keydown` 事件进入真实按键处理链；没有直接调用列表 sink/lift/split 命令来冒充按键。
- 输入前缀和正文采用每个字符 `keydown` → `beforeinput` → 默认 DOM 文本插入 → `input`，再由真实 MutationObserver 读取 DOM 并执行输入规则。JSDOM 不执行浏览器默认编辑，因此测试只补默认文本节点插入和选区移动。此过程是合成浏览器编辑路径，不是真实物理键盘或原生 IME。
- 覆盖单项/子树/多项反向选区、空段、软换行、有序/普通/任务混合、表格前后、单元格内列表、只读和组合边界。
- 修改类结构操作核对单次撤销/重做的源码精确恢复及组件卸载重挂；保存通过隔离 IPC 替身核对发送的准确正文，未把它称为本轮原生写盘验收。
- 单元格列表另用产品实际 parser 对保存的 Markdown 重新解析，核对列表文本、层级、任务状态和单元格数。

执行：

```sh
node scripts/test-markdown-list-shortcuts-deep.mjs
```

支持环境变量 `DEDITOR_TEST_FILTER` 选择单组。最终日志在忽略目录 `tests/artifacts/list-shortcuts-deep-2026-09-27/final.log`。
