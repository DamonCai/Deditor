## 本次完成的开发

- **远程图片下载**：显式操作当前文档的 HTTP(S) 图片，重复目标只下载一次，按实际内容判断格式，每张最多 20 MB；限制重定向和超时。成功后只改图片引用，保留片段标记；失败引用不变，正文改动可撤销。
- **PicGo 图床**：使用本机 PicGo HTTP 服务，发送经过校验的本地图片路径，读取返回 URL 后替换引用。端点只接受本机地址，不跟随重定向；可选令牌仅存于当前界面会话。下载与上传均可在当前图片完成后停止，并保护并发正文修改、标签路径变化及重复启动。只有显式点击上传才发送图片；只读模式禁用正文修改操作。
- **图片目录**：支持相对子目录及绝对目标目录，增加系统目录选择入口。YAML `typora-copy-images-to` 优先。源码粘贴、可视化添加、整理及下载共用保存逻辑。绝对目标写为显式文件 URL，中文、空格、百分号和井号只编码一次；`..`、无效目录和未展开的 `~` 不作为目标使用。旧相对 `save_image` 契约保持不变。
- **富文本脚注浮层**：两种模式共用已渲染定义内容，保留强调、代码、链接等；浮层位于正文编辑区之外。支持跳转、Tab 进入、Shift+Tab 返回、Esc 关闭并恢复引用焦点，避免重复 ID 与图表引用冲突。正文变动后关闭旧浮层，下次打开获取新内容。定义在阅读编辑中仍保留原文位置，Preview 仍集中在文末。
- **设置焦点**：完成或 Esc 关闭写作设置后恢复当前编辑区焦点，避免下一次撤销快捷键落在页面背景。
- **行内源码索引**：普通单行且不涉及上下文引用的编辑仅重建所在块的索引；多行、引用定义及结构歧义仍走完整解析。逐次与完整解析比对，保护原文范围与后续编辑。
- **文内目录性能**：普通正文输入不再触发目录全文解析/渲染。标题、保留块及相关引用变化才刷新；外部源内容更新、撤销也在编辑器同步后触发检查，避免目录滞后。

PicGo 配置依据其[官方服务说明](https://docs.picgo.app/gui/guide/advance)及[命令说明](https://docs.picgo.app/core/guide/commands)。应用只负责调用本机服务；具体图床账号由 PicGo 管理。
