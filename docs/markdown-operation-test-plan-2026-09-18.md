# 阅读编辑按操作类型测试（2026-09-18）

## 范围与方法

基线为 `1e7267d`。用户要求从回车、表格回车、整篇复制等现象中提取操作类型，按类型设计并执行测试，而不是只检查这些例子。本轮只使用自建样例，先验证现有行为；测试发现的问题单列，不通过调整期望掩盖。

测试单位是“初始文档与选区 → 操作 → 中间状态 → 下一操作 → 保存或撤销后的状态”。例如 Enter 属于结构拆分，表格内 Enter 是该操作在容器约束下的变体；整篇复制属于选区序列化，粘贴属于结构反序列化，粘贴后撤销属于事务边界与历史恢复。

## 类型与验收标准

| 类型 ID | 类型 | 代表操作与组合 | 必须核对 |
| --- | --- | --- | --- |
| input | 文字输入与替换 | 逐字输入、选中覆盖、配对符号、软换行、组合输入确认/取消 | 字符、空白、格式继承、输入落点；组合输入模拟不代替真实输入法 |
| structure | 结构创建、拆分、合并与删除 | Enter/退格/Delete、缩进/退缩进、空项退出、表格增删行列 | 层级和表格尺寸、相邻内容、文首文末出口；撤销后可继续输入 |
| selection | 光标、选区与焦点 | 左右上下、跨块正反选区、整行整列/整篇选择、鼠标与键盘入口 | 选中的实际范围、焦点所有者、复制/删除范围、后续输入位置 |
| clipboard | 内容搬运与格式转换 | 复制/剪切/粘贴，纯文本/Markdown/HTML/TSV/图片，整篇和局部 | 顺序、文字、结构、链接/属性、空白；源文档复制不变、粘贴独立撤销 |
| format | 格式和定向修改 | 标题、行内格式、链接、查找/替换、替换为空 | 只影响目标、未改区原文保真、取消后的焦点、重复操作 |
| embedded | 内嵌编辑器与特殊块 | 代码、图表、公式、HTML、图片进入/退出、清空、语言/模式切换 | 内外编辑器焦点交接、原文、异步结果、删除后可续写 |
| history | 操作事务与可逆性 | 输入→拆分→续写→多次撤销/重做；粘贴/剪切→撤销→直接续写 | 操作分组、正文与选区一起恢复、重做分支、跨文件历史隔离 |
| lifecycle | 视图与文档生命周期 | 编辑/预览/阅读切换、标签切换、左右分屏、隐藏/销毁/重建 | 正文同步、各视图光标滚动、隐藏实例不接收输入、异步过期保护 |
| persistence | 保存、关闭与异常恢复 | 保存/另存、保存失败继续编辑再试、关闭取消、草稿恢复 | 写入最新内容、失败不丢草稿、错误可见、关闭与异步保存顺序 |
| presentation | 呈现与源文保真 | 重新解析、预览复用、代码行数、图表布局、安全 HTML 展示 | 打开/切换不改原文、未改块复用、无漏内容；真实尺寸需界面验证 |

## 交叉维度

- 内容：正文、标题、引用、普通/有序/任务列表、表格及格内列表、行内格式、代码、图表、公式、HTML、图片、脚注。
- 位置和状态：文首/中部/文末、块首/尾、空文档/空块/只有软换行的块、单一块/相邻块/嵌套块、表头/首末格。
- 选区：无选区、单字/多字、跨格式、跨块正反向、多格/行/列、整篇；中文、组合字符、空白和换行。
- 时序：单步、连续重复、停顿超过历史分组间隔、撤销后立即续写、重做后继续操作、异步完成前切换。
- 运行环境：可编辑/只读、亮/暗、宽/窄窗口、多标签/分屏；DOM 自动化、真实浏览器、原生剪贴板/文件系统分别登记。

不声称穷举所有笛卡尔组合：每类覆盖主路径、边界、连续操作三个维度，并保留已有问题回归。原生剪贴板、鼠标命中/拖选、实际输入法、操作系统菜单需独立验证，自动化模拟通过不能填入这些格子。

## 执行与报告

统一入口按类型关联现有测试，重复关联的脚本只执行一次。某个脚本失败后继续其他脚本，最后返回失败状态；每个脚本保存独立日志，报告记录 Git 基线、类型、耗时、退出状态和失败输出。统计的是脚本与已输出的检查点，不换算成“全部操作覆盖率”。

本次新增整篇复制/剪切再粘贴的检查，直接触发编辑器剪贴板事件并消费实际生成的两种 MIME 内容，覆盖富文本结构和纯 Markdown 通道。底层剪贴板为模拟对象，保存为模拟接口，重建为组件重挂载。

## 已确认问题 H-TAB-01：增行与随后输入的撤销粒度随快慢变化

验收标准：结构操作和随后的文字输入有独立历史边界，与已有 Enter、列表缩进行为保持一致。

自建最小文档：

```markdown
| A | B |
| --- | --- |
| one | two |
```

1. 光标放在 `two` 后，按 Tab 新增一行。
2. 在新行首格输入 `X`。
3. 撤销一次。

| 操作时序 | 期望 | 实测 |
| --- | --- | --- |
| 增行后立即输入 | 撤销 X，保留新增空行 | 整个新增行一起消失 |
| 增行后停顿超过 750ms 再输入 | 撤销 X，保留新增空行 | 保留新增空行 |

DOM 自动化固定时间差为 0/1000ms，真实浏览器分别使用紧接按键和分步停顿，两者均复现。重做可恢复新增行和文字，未观察到不可恢复的数据丢失。

横向检查普通列表缩进、任务缩进、列表反缩进、引用拆分，各自 0/1000ms 两种时序都能独立撤销输入；五类结构操作共 10 个时序变体，只有表格立即输入变体不满足上述标准。新增断言位于 `scripts/test-markdown-enter-history.mjs`，未跳过或标为预期成功。

代码线索：`tableKeys.ts` 的末格 Tab 使用 `addRowAfter` 后直接派发事务；阅读编辑的事务边界目前识别 Enter、选区删除及带 `deditor-list-operation` 标记的结构操作。`MarkdownSession` 在 750ms 内合并相邻编辑。这里只记录定位线索，本轮没有修改产品实现。

## English

This audit classifies editing by operation semantics, state, selection, timing and lifecycle, rather than by a few reported keys. The runner deduplicates suites, continues after failures and writes per-suite evidence. A confirmed timing-dependent undo boundary exists when typing immediately after Tab creates a table row. The regression remains failing; no product fix is included. Native clipboard, OS menus and real IME acceptance remain separate from DOM and browser checks.

## 后续补充：FENCE-SOURCE-01（2026-09-19，已修复）

用户报告添加 PlantUML 后表格保存损坏，实际是在逐字输入围栏时就误删了相邻源码。仅测试表格或单个围栏不足以发现，触发组合还包括文末引用定义。已把“文字输入 → 块转换 → 局部源码投影 → 保存 → 独立重解析 → 撤销重做 → 重开续写”加入表格 F06，覆盖四种围栏语言、表前/表后/单元格、脚注与 CRLF、保存格式化开关。每个字符都检查未改表格及后文，防止只检查编辑 DOM 而漏掉保存源文损坏。

新增两组 12 组合后，26 表格专项通过；完整 34 执行项仍为 33 通过、H-TAB-01 失败。真实浏览器及 macOS 文件保存重开也已验证，输入方式与平台边界见 [修复记录](markdown-fence-table-save-fix-2026-09-19.md)。分类入口补齐表格专项的新类型标签，本次完整报告在补标签前启动，执行项与用例未减少。
