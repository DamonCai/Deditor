# 大规模 Markdown 真实界面性能补测

2026-09-22。仅自建样例，入口 `tests/markdown-performance-matrix.html`，使用实际 EditorPane、8 个视图 MRU、共享历史、Preview 和 DiffView。基线为 `0fe428d` 冻结树，整合版含本次配对、词典、目录/初始 NodeView 优化与 DiffView 行复用。浏览器 692×798；另在词典/配对功能验收中覆盖 720px 暗色及中文亮色。没有访问用户文档。

## 测量定义

- `input-two-frames`：可信 beforeinput 到两个 requestAnimationFrame 回调，记录每个事件独立样本，非操作系统按键延迟，也不等于异步预览完成。每组头/中/尾各 30 个字符，最终精确出现一次 `qwertyuiopasdfghjklzxcvbnm1234`，撤销恢复完整原文。
- `preview-after-last-input`：末次输入到实际 MarkdownPreviewDocument DOM 提交并再过两帧，包含 80ms 合并窗口；不宣称远程图表/媒体全部就绪。
- `mount-ready-after-imports`：模块导入结束后到活动编辑桥和完整预览就绪；不包含网络/模块下载。主题计时等待实际 DOM 更新的主题，不能用旧预览文本判断新主题完成。
- Profiler 只包实际编辑区/历史区，不在每键更新报告。不同事件窗口可能重叠，逐键 commit 数不能直接累加成独立提交总量。
- 批量逐键工具在 1MB 阅读中超时的样本已作废；重置原文后用每键独立调用重测，30 个可信事件与精确源码均核对。最终 1MB split 同样用独立按键调用；因此不同输入节奏的数据仅作覆盖，不能宣称该路径获得加速。

## 超过八标签

实际访问十个不同 Markdown，再回到 1MB 文件。源码视图冷恢复约 41–42ms，阅读视图冷恢复 5875.2ms，实际保留阅读视图 8 个，十个文件内容均完整。

源码光标偏移恢复相同。未修改样例前后首可见源码行均 10242，光标纵坐标差 0.22px；scrollTop 数值因 CodeMirror 重建高度估算变化，不能直接当作跳转失败。有未保存输入样例前后光标偏移均 1048657，仍在视口内，首可见行 10241→10243（约 60px）；恢复不是逐像素承诺。冷恢复后撤销精确还原原文。阅读冷恢复本轮核对完整正文，未从无源码桥的状态虚构光标数值。

## 300 个代码围栏

32,482 字节、300 个 TypeScript 围栏，超过 256 条高亮缓存预算。三轮在第 150 块逐键编辑、等实际预览出现、撤销、亮暗切换；全部 300 块仍在 DOM，内容一致。

基线三次主题 308.1 / 280.5 / 294.6ms；整合版 327.0 / 284.4 / 328.0ms。整合版末键到预览 186.1 / 178.2 / 170.3ms。此路径没有相关算法改动，不称性能改善；缓存淘汰没有减少可打开或可展示内容。

## 千 / 万行历史

真实 DiffView：每百行一处修改为稀疏、每三行一处为密集。最终每组 20 次导航（千行稀疏含返回），支持全展开/折叠切换，全部 10,000 行实际保留。

确认原实现跳转差异会重新 render 全部展开行。本次仅对 Row 做 React.memo，保留同一 DOM、全文内容、滚动与导航方式。

| 场景 | 导航中位，基线→整合 | React render 时间中位，基线→整合 |
| --- | --- | --- |
| 1,000 行稀疏 | 17.7→11.5ms | 11.0→1.6ms |
| 1,000 行密集 | 19.1→12.4ms | 13.9→5.0ms |
| 10,000 行稀疏 | 123.9→45.5ms | 89.5→10.9ms |
| 10,000 行密集 | 167.0→79.0ms | 129.2→41.6ms |

万行每次导航 React commit 均为 1，减少的是参与渲染的行，不是伪造 commit 数下降。基线千行稀疏测九次向后（共十处差异），其余导航二十次。

万行稀疏全展开/收起各重复三次：展开中位 1204.8→1082.1ms，收起 138.8→117.0ms。初次个别样本 1131.0→1300.9ms，说明单次波动较大；即使优化后仍需创建全部 DOM，不能把导航收益套用于首次展开。

## 实际磁盘搜索

新增 `ipc_bench::find_in_files_5k_repeated_matrix`，写入临时目录的 5,000 个约 1KB 文件，区分大小写、忽略大小写和零命中各五轮。断言扫描全部 5,000 文件、125/250/0 命中、行列和结果顺序稳定、无截断。与 stub 不同，实际执行文件系统枚举和读取；文件刚写入，可能命中操作系统缓存，不称物理冷盘测试。最终完整 `perf:all` 通过；五轮中位分别为 72.785ms（125 命中）、71.364ms（250 命中）、65.087ms（零命中）。Rust 性能测试 9/9 通过，完整矩阵见 `tests/artifacts/markdown-four-items-2026-09-22/rust-search-matrix-summary.json`。
