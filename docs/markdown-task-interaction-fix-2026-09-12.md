# 任务列表删除与缩进修复（2026-09-12）

## 范围与复现

用户反馈 `untitled.md` 空的已完成父任务在光标处不能退格，任务列表除了打勾外难以编辑；随后明确 Tab 是整条任务向右缩进一级。此前代码块点击保持原状的修复见 [代码焦点记录](markdown-code-focus-fix-2026-09-12.md)。本次只处理任务交互及对应保存、预览，不扩展为全部 Markdown 或钉钉交互验收。

原文件只读，在忽略的浏览器副本和 `/tmp/deditor-task-native-review/tasks.md` 中验证（基准副本为 `/tmp/deditor-task-native-user-copy.md`）。原文件 SHA-256：`2ca8a009c96fb94bf7b6c8d544206a7d0d916d01a17ba59e2bb70a1a7a7f5bba`。

实际内容为 `* [x] <br />`，其下有三个子任务。旧版在空段首退格时合并了前面的段落，却留下空任务框；换行标记后退格也不能正常退出。第一项 Tab 被消耗但无任何缩进，已有子项继续 Tab 同样可能没有反应。

## 修改

- 空任务中的单个 HTML 换行占位可由 Backspace / Enter 正常退出；在有文字的任务行首退格逐级减少缩进，再退出任务。子任务、文字、勾选状态均保留。
- Tab / Shift+Tab 支持连续缩进和反向缩进、多项选择、带子任务的整组移动；修正前一项已有独立缩进或父项已有独立缩进时一次跳多级的问题。表格中的 Tab 仍导航单元格。
- 已完成任务回车新建未完成任务；空任务回车退出；Shift+Enter 在任务中换行。同行末 Delete 合并相邻同级任务的文字，并保留后项的子任务。
- 每次结构操作单独记录撤销边界；修正仅修改任务属性时的原文同步判断，保存后重新解析仍保持缩进。
- 嵌套复选框的负外边距不再层层抵消缩进。阅读编辑与真实预览每级水平位移相同。

标准 Markdown 无法表达没有前一项作为父项的首条任务独立缩进。普通嵌套继续使用标准列表；需要独立缩进时使用隐藏 HTML 注释 `<!-- deditor-task-indent:N -->` 保存附加级数。DEditor 阅读编辑、预览、保存重开和 HTML 复制都识别它；其他 Markdown 编辑器可保留任务文字与勾选，但不保证显示这部分附加缩进。这是本次实现的格式兼容边界。
